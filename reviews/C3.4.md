## T3.4.1 reviewer amendment — Plotly without pandas

The builder correctly reported BLOCKED. With the installed plotly 7.1, `plotly.express.px.line(x=..., y=...)` raises `NotImplementedError: Pandas installation is required if no dataframe is provided`, and pandas is not a site dependency. Adding a heavy package just for a demo is not justified. `plotly.graph_objects` draws the same hoverable line chart without pandas (checked in `.venv`).

In **both** inserted Plotly cells (English and Persian), replace these lines:

```python
import numpy as np
import plotly.express as px

x = np.linspace(-3, 3, 61)
fig = px.line(x=x, y=np.tanh(x), labels={"x": "x", "y": "tanh(x)"}, title="Hover over the curve")
fig.show()
```

with exactly these lines:

```python
import numpy as np
import plotly.graph_objects as go

x = np.linspace(-3, 3, 61)
fig = go.Figure(go.Scatter(x=x, y=np.tanh(x), mode="lines"))
fig.update_layout(title="Hover over the curve", xaxis_title="x", yaxis_title="tanh(x)")
fig.show()
```
