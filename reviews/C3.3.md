## Visual review

Both style guides were checked at 1280 px and 375 px, in light and dark modes. These were correct:

- Headings, paragraphs, inline code and inline math inside Persian sentences.
- Lists, the quote, footnotes and `<details>`.
- Code blocks and outputs (LTR).
- Display math with its equation number.
- Cross-references (معادله / شکل / جدول) and the table and image captions.
- The mixed Persian/English sentences and Persian punctuation.
- At desktop width, callouts and code blocks line up with the body text.

Three defects were found:

1. **The callout accent bar is on the wrong side in RTL.** Quarto draws a 5 px coloured `border-left` on every callout. On Persian pages it should be on the right, the start side.
2. **The figure caption of executed-code figures is LTR in Persian.** The caption sits inside `.cell-output-display`, which `rtl.scss` forces LTR. So «شکل ۱: یک موج سینوسی.» is left-aligned and its final period jumps to the start.
3. **Plots are not responsive (both languages).** Executed-code images carry `width="591"`, and no stylesheet limits them. At 375 px the plot is 591 px wide inside a 309 px column and gets cut off. This affects the test posts too.

The manager tested all three fixes, the callout rule in a real build and the others in the live page:

- All five callout types get a right-hand bar in their own colour.
- The caption becomes RTL and right-aligned.
- Plots scale to 309 px wide while keeping their aspect ratio.

### Steps

1. Append this block, exactly as written, at the very end of `shared/styles/rtl.scss`, separated from the previous rule by one blank line:

```scss
/* Callouts: move Quarto's coloured accent border from the left to the right (start) side. */
html[dir="rtl"] div.callout.callout-style-default,
html[dir="rtl"] div.callout.callout-style-simple {
  border-left: 1px solid $table-border-color;
  border-right-width: $callout-border-width;
  border-right-style: solid;
}

@each $name, $info in $callouts {
  html[dir="rtl"] div.callout-#{$name}.callout {
    border-right-color: shift-color(map-get($info, "color"), $callout-border-scale);
  }
}

/* Figure captions of code output are Persian text, even though the output itself is LTR. */
html[dir="rtl"] .cell-output-display figcaption {
  direction: rtl;
  text-align: right;
}
```

2. Append this block, exactly as written, at the very end of `shared/styles/base.scss`, separated from the previous rule by one blank line:

```scss
/* Images (including plots with a fixed width attribute) never grow wider than the text column. */
main img {
  max-width: 100%;
  height: auto;
}
```
