## Findings

1. **Unpadded dates are accepted.** `--date 2026-1-5` passes `strptime`, exits 0, and writes `date: 2026-1-5` into both posts. The spec says the date must be `YYYY-MM-DD`.
2. **Drafts leak through the notebook format.** A post created with `make new-post` (so `draft: true`) and then built produces:
   - an empty stub for `public/posts/<folder>/index.html` (correct, because of `draft-mode: gone`);
   - a full `index.ipynb` with the whole draft text next to it.
   
   The listings, feed, sitemap and search correctly omit the draft. But anyone can fetch the notebook by URL once it is pushed, so every draft the owner pushes would be public. The safeguard belongs in the assembly step, so it also covers the hello-world posts when T7.3.1 marks them as drafts.

### Steps

1. `scripts/new_post.py`: before the `strptime` call, reject any `--date` that does not fully match `^\d{4}-\d{2}-\d{2}$`, using the existing message `error: date must be YYYY-MM-DD` and exit code 2. Change nothing else.
2. `scripts/assemble_site.py`: after both `copytree` calls and before creating `.nojekyll`, remove draft posts from the output:
   - For each language pair `("en", OUT / "posts")` and `("fa", OUT / "fa" / "posts")`, look at every folder `ROOT / lang / "posts" / <folder>` that contains `index.qmd` or `index.ipynb`.
   - For `index.qmd`, read the YAML front matter: the lines between the first line `---` and the next line `---`. For `index.ipynb`, read the first cell's source the same way, if it is a `raw` cell that starts with `---`.
   - If any front-matter line matches `^draft:\s*true\s*$`, delete the output folder `<out posts dir>/<folder>` (if it exists) with `shutil.rmtree`, and print `skipped draft: <lang>/posts/<folder>`.
   - Use the standard library only, with no YAML library. Keep the docstring, every existing check and message, and the final `assembled public/ (...)` line, whose total counts the files in `OUT` after removal.
