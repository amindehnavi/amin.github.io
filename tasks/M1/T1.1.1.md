## Goal
Create the empty folder structure of the project plus `.gitignore`, `.editorconfig` and `README.md`.

## Background (read only, don't act on it)
- `shared/` holds files used by both language sites. It is copied into `en/assets/` and `fa/assets/` at build time, and those copies are ignored by git.
- `en/` and `fa/` will each be a Quarto website project.
- Git doesn't track empty folders, so each empty folder gets an empty file called `.gitkeep`.

## Files you may create or change
- `.gitignore`
- `.editorconfig`
- `README.md`
- `.gitkeep` (empty) inside each of these folders: `shared/styles/`, `shared/fonts/`, `shared/js/`, `shared/images/`, `shared/files/`, `shared/data/`, `en/`, `fa/`, `scripts/`, `prompts/`, `templates/`, `reports/`, `reviews/`, `.github/workflows/`

## Steps
1. Create every folder listed above, each with an empty `.gitkeep` file.
2. Create `.gitignore` with this **exact content**:
~~~text
# Quarto build output
/en/_site/
/fa/_site/
/public/
/en/.quarto/
/fa/.quarto/
.quarto/

# Copies of shared/ made by scripts/sync_shared.py (never edit these)
/en/assets/
/fa/assets/

# Temporary working folder for agents and scripts
/.tmp/

# Python
.venv/
__pycache__/
*.pyc
.ipynb_checkpoints/

# OS / editors
.DS_Store
.vscode/
.idea/

# Secrets (never commit)
.env
~~~
3. Create `.editorconfig` with this **exact content**:
~~~text
root = true

[*]
charset = utf-8
end_of_line = lf
insert_final_newline = true
indent_style = space
indent_size = 2
trim_trailing_whitespace = true

[Makefile]
indent_style = tab

[*.py]
indent_size = 4

[*.md]
trim_trailing_whitespace = false
~~~
4. Create `README.md` with this **exact content** (replace the placeholder):
~~~markdown
# {{GITHUB_USERNAME}}.github.io

Source of my bilingual (English / فارسی) personal website and ML blog, built with [Quarto](https://quarto.org).

- English: https://{{GITHUB_USERNAME}}.github.io/
- فارسی: https://{{GITHUB_USERNAME}}.github.io/fa/

See `PLAN.md` for the plan and `ROADMAP.md` for the build roadmap.
~~~

## Do NOT
- Do not create any other files or folders.
- Do not add `_freeze` to `.gitignore`. Those folders **must** be committed.

## Verify
```bash
find shared en fa scripts prompts templates reports reviews .github -name .gitkeep | sort
```
```bash
git check-ignore -v en/_site/a fa/_site/a public/a .venv/a en/assets/a fa/assets/a .tmp/a
```
```bash
git check-ignore en/_freeze/a; echo "exit=$?"
```
```bash
grep -c "{{" README.md; echo "exit=$?"
```

## Done when
- [ ] The first command lists 14 `.gitkeep` files
- [ ] The second command prints one matching rule for each of the 7 paths
- [ ] The third command prints `exit=1` (`_freeze` is NOT ignored)
- [ ] The fourth command prints `0` and then `exit=1` (no placeholders left)
