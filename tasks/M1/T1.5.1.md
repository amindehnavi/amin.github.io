## Goal
Create the CI workflow that builds both sites on every push to `main` and deploys `public/` to GitHub Pages.

## Background (read only)
- CI uses the Quarto version from `.quarto-version`.
- CI installs only the light site-level `requirements.txt`. Code outputs come from the committed `_freeze/` folders, so nothing heavy runs.
- `make build PY=python` uses the CI's Python instead of `.venv`.

## Files you may create or change
- `.github/workflows/publish.yml`

## Steps
1. Create `.github/workflows/publish.yml` with this **exact content**:
~~~yaml
name: Publish site

on:
  push:
    branches: [main]
  workflow_dispatch:

permissions:
  contents: read
  pages: write
  id-token: write

concurrency:
  group: pages
  cancel-in-progress: true

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - name: Check out
        uses: actions/checkout@v4

      - name: Read Quarto version
        id: qv
        run: echo "version=$(cat .quarto-version)" >> "$GITHUB_OUTPUT"

      - name: Set up Quarto
        uses: quarto-dev/quarto-actions/setup@v2
        with:
          version: ${{ steps.qv.outputs.version }}

      - name: Set up Python
        uses: actions/setup-python@v5
        with:
          python-version: "3.12"

      - name: Install site Python packages
        run: pip install -r requirements.txt

      - name: Build both sites
        run: make build PY=python

      - name: Upload Pages artifact
        uses: actions/upload-pages-artifact@v3
        with:
          path: public

  deploy:
    needs: build
    runs-on: ubuntu-latest
    environment:
      name: github-pages
      url: ${{ steps.deployment.outputs.page_url }}
    steps:
      - name: Deploy to GitHub Pages
        id: deployment
        uses: actions/deploy-pages@v4
~~~
   Note: `${{ ... }}` here is GitHub Actions syntax, **not** one of our placeholders. Keep it exactly.
