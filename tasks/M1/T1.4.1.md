# T1.4.1 — Site assembly script and `make build` / `make serve`

## Goal
Write `scripts/assemble_site.py`, which combines the two rendered sites into one folder `public/` (English at the root, Persian under `public/fa/`), and add `build` and `serve` targets to the Makefile.

## Files you may create or change
- `scripts/assemble_site.py`
- `Makefile`

## Steps

### 1. `scripts/assemble_site.py`: spec
- Standard library only.
- Docstring: `"""Combine en/_site and fa/_site into public/ (Persian under public/fa/). Run after rendering both sites."""`
- `ROOT = Path(__file__).resolve().parent.parent`
- `EN = ROOT / "en" / "_site"`, `FA = ROOT / "fa" / "_site"`, `OUT = ROOT / "public"`
- Checks, in this order. Each error goes to **stderr** and exits with code **1**:
  1. `EN` is not a directory → `error: en/_site not found - run "make render-en" first`
  2. `FA` is not a directory → `error: fa/_site not found - run "make render-fa" first`
  3. `(EN / "fa")` exists → `error: en/_site/fa exists and would collide with the Persian site`
- If `OUT` exists, delete it (`shutil.rmtree`).
- `shutil.copytree(EN, OUT)`, then `shutil.copytree(FA, OUT / "fa")`
- Create an empty file `OUT / ".nojekyll"` (this tells GitHub Pages not to run Jekyll).
- Count the files under `EN`, under `FA`, and under `OUT`, and print exactly:
  `assembled public/ (<total> files: en <n_en>, fa <n_fa>)`
- Exit **0**. Use the `def main() -> int:` and `sys.exit(main())` pattern.

### 2. `Makefile`: add targets
Make exactly these three edits (TAB at the start of recipe lines):
1. Replace the `.PHONY` line with:
~~~make
.PHONY: help sync preview-en preview-fa render-en render-fa build serve clean
~~~
2. In the `help` target, add these two lines **before** the `make clean` line:
~~~make
	@echo "make build       render both sites and assemble them into public/"
	@echo "make serve       build, then serve public/ at http://localhost:8000"
~~~
3. Add these targets **between** the `render-fa` target and the `clean` target:
~~~make
build: render-en render-fa
	$(PY) scripts/assemble_site.py

serve: build
	@echo "Open http://localhost:8000  (Ctrl+C to stop)"
	$(PY) -m http.server 8000 --directory public

~~~

## Do NOT
- Don't change any other Makefile lines.
- Don't change `en/` or `fa/` files.

```

mkdir -p .tmp && (.venv/bin/python -m http.server 8765 --directory public >/dev/null 2>&1 & echo $! > .tmp/srv.pid) && sleep 1 && curl -s -o /dev/null -w "%{http_code}\n" http://localhost:8765/fa/ && curl -s -o /dev/null -w "%{http_code}\n" http://localhost:8765/fa/posts/2026-10-hello-world/ ; kill "$(cat .tmp/srv.pid)"; rm -f .tmp/srv.pid
```
```bash
rm -rf fa/_site && (.venv/bin/python scripts/assemble_site.py; echo "exit=$?")
```
```bash
make build >/dev/null && echo "rebuilt"
```
