## Goal
Write `scripts/sync_shared.py`, which copies `shared/` into `en/assets/` and `fa/assets/`, and a `Makefile` with the base commands.

## Background (read only)
- `shared/` is the only place where styles, fonts, scripts, images, files and data are edited.
- Each Quarto project (`en/`, `fa/`) can only use files inside its own folder, so we copy `shared/` into each project as `assets/` before every render.
- `en/assets/` and `fa/assets/` are already in `.gitignore`.

## Files you may create or change
- `scripts/sync_shared.py`
- `Makefile`

## Steps

### 1. `scripts/sync_shared.py`: spec
- Standard library only (`pathlib`, `shutil`, `sys`).
- Starts with a docstring: `"""Copy shared/ into en/assets/ and fa/assets/. Run: .venv/bin/python scripts/sync_shared.py"""`
- `ROOT = Path(__file__).resolve().parent.parent`
- `SRC = ROOT / "shared"`
- `DESTS = [ROOT / "en" / "assets", ROOT / "fa" / "assets"]`
- If `SRC` is not a directory: print `error: shared/ folder not found` to **stderr** and exit with code **1**.
- For each `dest` in `DESTS`, in order:
  1. Safety check: if `dest.name != "assets"` or `dest.parent.name not in ("en", "fa")`, print `error: refusing to delete <dest>` to stderr and exit **1**.
  2. If `dest` exists, delete it with `shutil.rmtree(dest)`.
  3. `shutil.copytree(SRC, dest, ignore=shutil.ignore_patterns(".gitkeep", ".DS_Store"))`
  4. Count the files (not folders) under `dest` and print exactly: `synced shared/ -> en/assets/ (N files)`, using `fa/assets/` for the second one.
- Exit with code **0**.
- Wrap the logic in `def main() -> int:` and finish with `if __name__ == "__main__": sys.exit(main())`.

### 2. `Makefile`: exact content
**Every indented line below must start with one TAB character, not spaces.**
~~~make
# Build commands for the bilingual site. Run `make help` for the list.
PY ?= .venv/bin/python

# Use the project virtualenv for Quarto's Jupyter kernel when it exists.
ifneq ($(wildcard .venv/bin/python),)
export QUARTO_PYTHON := $(abspath .venv/bin/python)
endif

.PHONY: help sync preview-en preview-fa render-en render-fa clean

help:
	@echo "make sync        copy shared/ into en/assets and fa/assets"
	@echo "make preview-en  live preview of the English site"
	@echo "make preview-fa  live preview of the Persian site"
	@echo "make render-en   render the English site into en/_site"
	@echo "make render-fa   render the Persian site into fa/_site"
	@echo "make clean       delete all build output"

sync:
	$(PY) scripts/sync_shared.py

preview-en: sync
	quarto preview en

preview-fa: sync
	quarto preview fa

render-en: sync
	quarto render en

render-fa: sync
	quarto render fa

clean:
	rm -rf public en/_site fa/_site en/assets fa/assets en/.quarto fa/.quarto
~~~
