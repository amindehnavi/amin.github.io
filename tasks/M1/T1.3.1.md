## Goal
Download the open-source Persian font **Vazirmatn** (SIL Open Font License) from its official GitHub releases and store the web font file plus its license in `shared/fonts/`.

## Background (read only)
- We self-host fonts because Google Fonts can be slow or blocked for readers in Iran.
- Official project: https://github.com/rastikerdar/vazirmatn

## Files you may create or change
- `shared/fonts/Vazirmatn-Variable.woff2` **or** (fallback) `shared/fonts/Vazirmatn-Regular.woff2` + `shared/fonts/Vazirmatn-Bold.woff2`
- `shared/fonts/Vazirmatn-OFL.txt`
- `.tmp/vazirmatn/` (temporary; you must delete it at the end, and it's git-ignored)

## Steps
1. Find the latest release's zip file URL:
```bash
curl -s https://api.github.com/repos/rastikerdar/vazirmatn/releases/latest | grep browser_download_url
```
   Use the URL that ends in `.zip`. If there are several, use the one whose name starts with `vazirmatn-v`.
2. Download and unzip it into `.tmp/vazirmatn/`:
```bash
mkdir -p .tmp/vazirmatn && curl -L -o .tmp/vazirmatn/vazirmatn.zip "<URL from step 1>" && unzip -q .tmp/vazirmatn/vazirmatn.zip -d .tmp/vazirmatn/unzipped
```
3. Find the variable web font:
```bash
find .tmp/vazirmatn/unzipped -iname "*.woff2" | sort
```
   - **Preferred:** a file named `Vazirmatn[wght].woff2` inside a folder named `webfonts` (but **not** a name containing `UI`, `RD`, `FD`, `NL` or `Round`). Copy it to `shared/fonts/Vazirmatn-Variable.woff2`.
   - **Fallback** (only if the preferred file doesn't exist): copy `Vazirmatn-Regular.woff2` and `Vazirmatn-Bold.woff2` from the `webfonts` folder (again, not the UI/RD/FD/NL/Round variants) to `shared/fonts/` with those exact names. Write **"Used fallback static fonts"** in the report.
4. Find the license file (`OFL.txt` or `LICENSE`) in the unzipped folder and copy it to `shared/fonts/Vazirmatn-OFL.txt`.
5. Delete the temporary folder: `rm -rf .tmp/vazirmatn`

## Do NOT
- Don't use any other download source.
- Don't commit the zip file or anything from `.tmp/`.
- Don't create CSS yet (that's T1.3.2).

## Verify

```bash
ls -la shared/fonts/
```
```bash

```
```bash

```

```bash
test ! -d .tmp/vazirmatn && echo "tmp removed"
```
