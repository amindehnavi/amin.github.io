# T1.5.2 — Push and check the live site

| | |
|---|---|
| Milestone › Checkpoint | M1 Foundation › C1.5 Deploy 🚦 GATE |
| Who | 👤 HUMAN (Owner) |
| Depends on | T1.5.1 |
| Time | ~20 min |

## Goal
Publish for the first time and check the live site with your own eyes, before asking for the M1 gate review.

## Steps
1. Push:
   ```bash
   git push && git push --tags
   ```
2. On GitHub, open the **Actions** tab. Wait for **Publish site** to finish with a green ✓. If it's red, copy the log of the failing step into a file `reports/T1.5.2-ci-log.txt` and ask the Reviewer.
3. Open `https://<username>.github.io/` and `https://<username>.github.io/fa/` and tick these:
   - [ ] English home page loads
   - [ ] Persian home page loads, with text right-aligned and the navbar mirrored (right-to-left)
   - [ ] Persian text uses the Vazirmatn font. In DevTools → Network → Font you see `Vazirmatn…woff2` loaded from **your github.io domain**
   - [ ] On the English test post, the **فارسی** link opens `/fa/posts/2026-10-hello-world/`, and **English** brings you back
   - [ ] On both test posts, the plot appears and the formulas render
   - [ ] In the Persian post, code blocks and display math are left-to-right, and the mixed sentence with `GPT-2` reads correctly
   - [ ] Persian search: click the search icon on `/fa/`, type `سلام` and the test post appears
   - [ ] The page works on your phone
4. Write your findings (✓ or a problem) into `reports/T1.5.2.md` and commit it:
   ```bash
   git add reports/T1.5.2.md && git commit -m "T1.5.2: live site check" && git push
   ```
5. Ask the Reviewer: **"Review checkpoint C1.5 — M1 gate"**.

## Done when
- [ ] The CI run is green
- [ ] The checklist is filled in and committed
