## Goal
Quarto ships no Persian translation for its interface text ("On this page", "Search", "Figure", "Copy", …). Create `fa/_language-fa.yml` by copying Quarto's English language file and translating **every value** into Persian.

## Files you may create or change
- `fa/_language-fa.yml`

## Steps
1. Find Quarto's English language file:
```bash
quarto --paths
```
   This prints two lines. The **second** line is Quarto's share folder. The file is `<share folder>/language/_language.yml`. Check it exists:
```bash
ls "$(quarto --paths | tail -1)/language/_language.yml"
```
   If it doesn't exist, run `find "$(quarto --paths | tail -1)" -name "_language.yml"` and use the result. If you still can't find it, STOP (BLOCKED).
2. Copy it to `fa/_language-fa.yml`.
3. In `fa/_language-fa.yml`, translate **only the values** into Persian:
   - Keep every **key** exactly as it is, in the same order. Don't add or remove keys.
   - Keep any placeholder text exactly as it is, e.g. `{0}`, `%s`, `${...}`, HTML tags.
   - Lines starting with `#` are comments. Leave them unchanged.
   - Put every translated value in double quotes.
   - Follow the Persian rules in AGENT_RULES §5 (ی/ک, نیم‌فاصله).
   - Use these exact terms where they apply, for consistency:

| English | Persian |
|---|---|
| On this page / Table of contents | در این صفحه / فهرست مطالب |
| Search | جستجو |
| Copy / Copied! | کپی / کپی شد! |
| Code / Show All Code / Hide All Code / View Source | کد / نمایش همهٔ کدها / پنهان‌کردن همهٔ کدها / مشاهدهٔ کد منبع |
| Figure / Table / Listing | شکل / جدول / کد |
| Equation | معادله |
| Abstract / References / Citation / Keywords | چکیده / منابع / ارجاع / کلیدواژه‌ها |
| Author / Authors / Affiliation | نویسنده / نویسندگان / وابستگی سازمانی |
| Published / Modified | تاریخ انتشار / آخرین ویرایش |
| Categories / All | دسته‌بندی‌ها / همه |
| Sort by / Default / Newest / Oldest / Filter | مرتب‌سازی / پیش‌فرض / جدیدترین / قدیمی‌ترین / فیلتر |
| Title / Date / Description / Reading time / min | عنوان / تاریخ / توضیحات / زمان مطالعه / دقیقه |
| No matching items | موردی یافت نشد |
| Back to top | بازگشت به بالا |
| Tip / Note / Warning / Important / Caution | نکته / یادداشت / هشدار / مهم / احتیاط |
| Theorem / Lemma / Corollary / Proposition / Conjecture | قضیه / لم / نتیجه / گزاره / حدس |
| Definition / Example / Exercise / Solution / Remark / Proof / Algorithm | تعریف / مثال / تمرین / پاسخ / ملاحظه / اثبات / الگوریتم |

## Do NOT
- Don't edit Quarto's original file.
- Don't change `fa/_quarto.yml` (it doesn't exist yet; T1.3.4 creates it).

## Verify
Replace `<ENGLISH_FILE>` with the path you found in step 1:
```bash
.venv/bin/python -c "
import yaml
en = yaml.safe_load(open('<ENGLISH_FILE>', encoding='utf-8'))
fa = yaml.safe_load(open('fa/_language-fa.yml', encoding='utf-8'))
print('keys en:', len(en), 'keys fa:', len(fa))
print('missing:', sorted(set(en) - set(fa)))
print('extra:', sorted(set(fa) - set(en)))
same = [k for k in en if isinstance(en[k], str) and en[k] == fa.get(k)]
print('untranslated:', same)
"
```
```bash
grep -c "[يك]" fa/_language-fa.yml; echo "exit=$?"
```

## Done when
- [ ] Both key counts are equal, and `missing` and `extra` are empty lists
- [ ] `untranslated` is empty, or lists only values that must stay the same (e.g. a symbol). Explain each one in the report
- [ ] The Arabic-letter check prints `0` and `exit=1`
