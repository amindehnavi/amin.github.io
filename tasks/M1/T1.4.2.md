# T1.4.2 — Language switcher

| | |
|---|---|

## Goal
Add a small script, included on every page of both sites, that points the navbar language link at **the same page in the other language**, and falls back to the other language's home page when that page doesn't exist.

## Background (read only)
- English page `/posts/x/` ↔ Persian page `/fa/posts/x/`.
- The navbar links are found by their `aria-label` (`Read in Persian` / `Read in English`), which T1.2.1 and T1.3.4 set.
- The switcher only works on the **assembled** site (`make serve` or the live site), not in `quarto preview`. That's expected.

## Files you may create or change
- `shared/js/lang-switch.html`
- `en/_quarto.yml` (one line added)
- `fa/_quarto.yml` (one line added)

## Steps
1. Create `shared/js/lang-switch.html` with this **exact content**:
~~~html
<script>
// Language switcher: points the navbar language link at the same page in the other language.
// English pages live at /..., Persian pages at /fa/... (same folder names).
(function () {
  var links = document.querySelectorAll(
    'a[aria-label="Read in Persian"], a[aria-label="Read in English"]'
  );
  if (!links.length) return;
  var path = window.location.pathname;
  var isPersian = path === "/fa" || path.indexOf("/fa/") === 0;
  var target = isPersian ? (path.replace(/^\/fa/, "") || "/") : "/fa" + path;
  var fallback = isPersian ? "/" : "/fa/";
  links.forEach(function (a) { a.setAttribute("href", fallback); });
  fetch(target, { method: "HEAD" })
    .then(function (r) {
      if (r.ok) links.forEach(function (a) { a.setAttribute("href", target); });
    })
    .catch(function () {});
})();
</script>
~~~
2. In **both** `en/_quarto.yml` and `fa/_quarto.yml`, under `format:` → `html:`, add this line directly **after** the `html-math-method: mathjax` line, with the same indentation (4 spaces):
~~~yaml
    include-after-body: assets/js/lang-switch.html
~~~

## Do NOT
- Don't change any other line in the config files.
