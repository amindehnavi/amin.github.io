## Goal
Create the minimal English Quarto website in `en/`: its config, a placeholder home page and an empty blog listing.

## Background (read only)
- The English site will be served at `https://{{GITHUB_USERNAME}}.github.io/`.
- The navbar link with `aria-label: "Read in Persian"` is used later by the language-switch script. Keep that label exactly as written.
- `assets/` is the copy of `shared/` made by `make sync`.

## Files you may create or change
- `en/_quarto.yml`
- `en/index.qmd`
- `en/blog.qmd`
- `en/posts/.gitkeep` (empty)

## Steps
1. Create `en/_quarto.yml` with this **exact content** (replace placeholders):
~~~yaml
project:
  type: website
  resources:
    - assets/**

lang: en
date-format: "MMMM D, YYYY"

execute:
  freeze: auto

website:
  title: "{{NAME_EN}}"
  site-url: "https://{{GITHUB_USERNAME}}.github.io/"
  repo-url: "https://github.com/{{GITHUB_USERNAME}}/{{GITHUB_USERNAME}}.github.io"
  draft-mode: gone
  navbar:
    left:
      - href: index.qmd
        text: "Home"
      - href: blog.qmd
        text: "Blog"
    right:
      - href: "https://{{GITHUB_USERNAME}}.github.io/fa/"
        text: "فارسی"
        aria-label: "Read in Persian"

format:
  html:
    theme: cosmo
    toc: true
    code-copy: true
    html-math-method: mathjax
~~~
2. Create `en/index.qmd` with this **exact content**:
~~~markdown
---
title: "{{NAME_EN}}"
subtitle: "{{TAGLINE_EN}}"
---

This site is under construction. The English and Persian versions are being built.
~~~
3. Create `en/blog.qmd` with this **exact content**:
~~~markdown
---
title: "Blog"
listing:
  contents: posts
  sort: "date desc"
  type: default
  categories: true
  feed: true
page-layout: full
title-block-banner: false
---
~~~
4. Create the empty file `en/posts/.gitkeep`.

## Do NOT

- Don't create anything in `fa/`.
