# T1.3.2 — RTL stylesheet and font CSS

## Goal
Create the two style files used only by the Persian site: a plain CSS file that loads Vazirmatn, and an SCSS layer that keeps code and math left-to-right inside right-to-left pages.

## Background (read only)
- `@font-face` goes in a **plain CSS file**, not SCSS, because Quarto compiles SCSS into another folder, which would break relative font paths. The CSS file ends up at `assets/styles/fonts-fa.css`, so `../fonts/` points at `assets/fonts/`.
- Quarto SCSS files need the special comment lines `/*-- scss:defaults --*/` and `/*-- scss:rules --*/`.
- The `.ltr` class lets writers mark English fragments inside Persian sentences: `[GPT-2]{.ltr}`.

## Files you may create or change
- `shared/styles/fonts-fa.css`
- `shared/styles/rtl.scss`

## Steps
1. Look in `shared/fonts/`.
   - If `Vazirmatn-Variable.woff2` exists, create `shared/styles/fonts-fa.css` with **exact content A**:
~~~css
/* Self-hosted Vazirmatn (SIL Open Font License, see ../fonts/Vazirmatn-OFL.txt). */
@font-face {
  font-family: "Vazirmatn";
  src: url("../fonts/Vazirmatn-Variable.woff2") format("woff2");
  font-weight: 100 900;
  font-style: normal;
  font-display: swap;
}
~~~
   - Otherwise (the fallback fonts exist), use **exact content B**:
~~~css
/* Self-hosted Vazirmatn (SIL Open Font License, see ../fonts/Vazirmatn-OFL.txt). */
@font-face {
  font-family: "Vazirmatn";
  src: url("../fonts/Vazirmatn-Regular.woff2") format("woff2");
  font-weight: 400;
  font-style: normal;
  font-display: swap;
}
@font-face {
  font-family: "Vazirmatn";
  src: url("../fonts/Vazirmatn-Bold.woff2") format("woff2");
  font-weight: 700;
  font-style: normal;
  font-display: swap;
}
~~~
2. Create `shared/styles/rtl.scss` with this **exact content**:
~~~scss
/*-- scss:defaults --*/
$font-family-sans-serif: "Vazirmatn", system-ui, -apple-system, "Segoe UI", Tahoma, sans-serif;

/*-- scss:rules --*/
/* Code, program output and display math always read left-to-right. */
pre,
div.sourceCode,
.cell-output,
.cell-output-stdout,
.cell-output-stderr,
.cell-output-display,
mjx-container[display="true"],
.katex-display {
  direction: ltr;
  text-align: left;
}

/* Inline code and inline math inside Persian sentences: isolate them. */
code,
kbd,
samp,
mjx-container:not([display="true"]) {
  direction: ltr;
  unicode-bidi: isolate;
}

/* Mark English fragments inside Persian text: [GPT-2]{.ltr} */
.ltr {
  direction: ltr;
  unicode-bidi: isolate;
  display: inline-block;
}

/* Persian text reads better with a little more line height. */
body {
  line-height: 1.9;
}
~~~

## Do NOT
- Don't touch `en/` or `fa/`.
- Don't add other CSS rules.
