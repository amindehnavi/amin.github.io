## Goal
Finish the blog listing pages (fields, paging, placeholder image, intro text) and add default settings shared by every post.

## Files you may create or change
- `shared/images/post-placeholder.svg`
- `en/blog.qmd`, `fa/blog.qmd`
- `en/posts/_metadata.yml`, `fa/posts/_metadata.yml`

## Steps
1. `shared/images/post-placeholder.svg`, **exact content**:
~~~xml
<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 1200 630">
  <rect width="1200" height="630" fill="#e7ecfb"/>
  <circle cx="420" cy="315" r="60" fill="#3b5bdb" opacity="0.85"/>
  <circle cx="600" cy="315" r="60" fill="#3b5bdb" opacity="0.6"/>
  <circle cx="780" cy="315" r="60" fill="#3b5bdb" opacity="0.35"/>
</svg>
~~~
2. Replace all of `en/blog.qmd` with this **exact content**:
~~~markdown
---
title: "Blog"
listing:
  contents: posts
  sort: "date desc"
  type: default
  categories: true
  feed: true
  page-size: 10
  image-placeholder: assets/images/post-placeholder.svg
  fields: [image, date, title, description, categories, reading-time]
page-layout: full
title-block-banner: false
toc: false
---

Notes on what I learn in machine learning and deep learning. Every post is also available in Persian.
~~~
3. Replace all of `fa/blog.qmd` with this **exact content**:
~~~markdown
---
title: "نوشته‌ها"
listing:
  contents: posts
  sort: "date desc"
  type: default
  categories: true
  feed: true
  page-size: 10
  image-placeholder: assets/images/post-placeholder.svg
  fields: [image, date, title, description, categories, reading-time]
page-layout: full
title-block-banner: false
toc: false
---

یادداشت‌هایی دربارهٔ آنچه در یادگیری ماشین و یادگیری عمیق می‌آموزم. همهٔ نوشته‌ها به انگلیسی هم در دسترس‌اند.
~~~
4. Create **both** `en/posts/_metadata.yml` and `fa/posts/_metadata.yml` with this **exact content**:
~~~yaml
# Default settings for every post in this folder.
toc: true
toc-depth: 3
~~~
