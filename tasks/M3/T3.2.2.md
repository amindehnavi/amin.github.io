## Goal
A script that creates a new post in **both** languages from the templates, with the same folder name, in one command.

## Files you may create or change
- `scripts/new_post.py`
- `Makefile`

## Steps

### 1. `scripts/new_post.py`: spec
- Standard library only (`argparse`, `datetime`, `pathlib`, `re`, `sys`).
- Docstring: `"""Create a new post in en/posts and fa/posts from templates/post. Run: make new-post ARGS='--slug my-topic --title-en "My Topic"'"""`
- Options:
  | option | required | default | meaning |
  |---|---|---|---|
  | `--slug` | yes | – | lowercase words joined by dashes |
  | `--title-en` | yes | – | English title |
  | `--title-fa` | no | `TODO(owner): Persian title` | Persian title |
  | `--date` | no | today, `YYYY-MM-DD` | post date |
  | `--series` | no | none | series id, e.g. `transformers-from-scratch` |
  | `--series-order` | no | none | integer position in the series |
- Validation (each failure: message to **stderr**, exit code **2**):
  - slug must match `^[a-z0-9]+(-[a-z0-9]+)*$` → `error: slug must be lowercase words joined by dashes`
  - date must parse as `YYYY-MM-DD` → `error: date must be YYYY-MM-DD`
  - `--series` given without `--series-order` (or the reverse) → `error: --series and --series-order must be used together`
  - `--series-order` must be an integer ≥ 1 → `error: --series-order must be a positive integer`
- Folder name = `<YYYY-MM of date>-<slug>`, e.g. `2026-12-self-attention`.
- If `en/posts/<folder>` **or** `fa/posts/<folder>` already exists → `error: post folder already exists: <folder>`, exit **2**. Create nothing.
- For each language (`en` with `templates/post/en.qmd` and title-en; `fa` with `templates/post/fa.qmd` and title-fa):
  1. Read the template as UTF-8.
  2. Replace `__TITLE__` with the title, escaping any `"` as `\"`, and `__DATE__` with the date.
  3. If a series is given, replace `__SERIES__` and `__SERIES_ORDER__`. Otherwise **delete the whole lines** that contain them.
  4. Create the folder and write `index.qmd` (UTF-8, LF).
- Print exactly:
  ```
  created en/posts/<folder>/index.qmd
  created fa/posts/<folder>/index.qmd
  ```
- Exit **0**. Use the `def main() -> int:` and `sys.exit(main())` pattern.

### 2. `Makefile`
Make exactly these edits (TAB before recipe lines):
1. Add `new-post` to the `.PHONY` line (just before `clean`).
2. In `help`, before the `make clean` line, add:
~~~make
	@echo "make new-post ARGS='--slug x --title-en \"X\"'  create a post in both languages"
~~~
3. Before the `clean:` target, add:
~~~make
new-post:
	$(PY) scripts/new_post.py $(ARGS)

~~~

## Do NOT
- Don't change the templates.
- Don't leave test posts behind (see Verify).
