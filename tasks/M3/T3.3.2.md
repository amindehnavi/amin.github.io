## Goal
Create the Persian twin of the style guide (`fa/style-guide.qmd`), so every element can be checked in right-to-left layout. Also add a section of **mixed Persian/English sentences**, the hardest case for RTL.

## Files you may create or change
- `fa/style-guide.qmd`
- generated files under `fa/_freeze/` (commit them)

## Steps
1. Copy `en/style-guide.qmd` to `fa/style-guide.qmd`.
2. In `fa/style-guide.qmd`, translate into Persian: the `title` and `description` values, all headings, all prose sentences, list items, the quote, callout texts and titles, the `fig-cap` text, the table **header** and caption text, image alt text, and the `<summary>` text. Use:
   - `title: "راهنمای نمایش"`
   - `description: "همهٔ اجزای محتوا برای بررسی طراحی. در منو پیوندی به آن نیست."`
3. Keep **exactly unchanged**: everything inside code blocks and `{python}` cells, all `#|` lines except the `fig-cap` text, all math, all labels (`{#eq-loss}`, `@fig-sine`, `{#tbl-models}`), URLs, image paths, `search: false`, and the numbers in the table body.
4. Write Persian digits (۰–۹) in prose, and keep Latin digits in code, math and the table body.
5. **Before** the `## Details` section, insert this section with **exact content**:
~~~markdown
## متن ترکیبی

مدل [BERT-base]{.ltr} حدود ۱۱۰ میلیون پارامتر دارد و با کتابخانهٔ [PyTorch]{.ltr} و کلاس `torch.nn.Transformer` پیاده‌سازی می‌شود.

آیا $p(y \mid x)$ همان احتمال شرطی است؟ بله، و در [GPT-2]{.ltr} برای هر توکن (Token) محاسبه می‌شود.

پرانتزها (مثل این) و «گیومه‌ها» و علامت‌های ، ؛ ؟ باید درست نمایش داده شوند.
~~~
