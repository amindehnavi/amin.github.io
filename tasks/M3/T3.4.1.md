## Goal
Prove that the two kinds of interactive figures work in both languages:
1. **Observable JS** (`{ojs}` cells, which run in the reader's browser): a temperature slider that reshapes a softmax distribution.
2. **Plotly** (a Python output): a hoverable curve.

## Files you may create or change
- `en/style-guide.qmd`
- `fa/style-guide.qmd`
- generated files under `en/_freeze/` and `fa/_freeze/` (commit them)

## Steps
1. In `en/style-guide.qmd`, insert this block **before** the `## Details` section (**exact content**):
~~~~markdown
## Interactive: Observable JS

Move the slider to change the softmax temperature.

```{ojs}
//| echo: false
viewof temperature = Inputs.range([0.1, 5], {value: 1, step: 0.1, label: "Temperature"})
```

```{ojs}
//| echo: false
logits = [2.0, 1.0, 0.1, -1.0]
```

```{ojs}
//| echo: false
probs = {
  const e = logits.map(z => Math.exp(z / temperature));
  const s = e.reduce((a, b) => a + b, 0);
  return e.map((v, i) => ({token: `token ${i + 1}`, p: v / s}));
}
```

```{ojs}
//| echo: false
Plot.plot({
  y: {domain: [0, 1], label: "probability"},
  marks: [Plot.barY(probs, {x: "token", y: "p", fill: "steelblue"}), Plot.ruleY([0])]
})
```

## Interactive: Plotly

```{python}
#| echo: false
import numpy as np
import plotly.express as px

x = np.linspace(-3, 3, 61)
fig = px.line(x=x, y=np.tanh(x), labels={"x": "x", "y": "tanh(x)"}, title="Hover over the curve")
fig.show()
```

~~~~
