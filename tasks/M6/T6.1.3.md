## Goal
A GitHub Actions workflow that the Owner starts by hand (Actions tab → *Announce post on Telegram* → Run workflow), giving a post slug. By default it only prints the message.

## Files you may create or change
- `.github/workflows/announce.yml`

## Steps
1. Create `.github/workflows/announce.yml` with this **exact content**. `${{ … }}` is GitHub syntax, so keep it as written:
~~~yaml
name: Announce post on Telegram

on:
  workflow_dispatch:
    inputs:
      slug:
        description: "Post folder name, e.g. 2026-12-self-attention"
        required: true
        type: string
      dry_run:
        description: "Only print the message (do not send)"
        required: true
        type: boolean
        default: true

permissions:
  contents: read

jobs:
  announce:
    runs-on: ubuntu-latest
    steps:
      - name: Check out
        uses: actions/checkout@v4

      - name: Set up Python
        uses: actions/setup-python@v5
        with:
          python-version: "3.12"

      - name: Install PyYAML
        run: pip install pyyaml

      - name: Announce
        env:
          TELEGRAM_BOT_TOKEN: ${{ secrets.TELEGRAM_BOT_TOKEN }}
          TELEGRAM_CHAT_ID: ${{ secrets.TELEGRAM_CHAT_ID }}
          SLUG: ${{ inputs.slug }}
          DRY_RUN: ${{ inputs.dry_run }}
        run: |
          if [ "$DRY_RUN" = "true" ]; then
            python scripts/notify_telegram.py --slug "$SLUG" --dry-run
          else
            python scripts/notify_telegram.py --slug "$SLUG"
          fi
~~~
