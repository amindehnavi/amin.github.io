## Goal
A script that builds a bilingual announcement for one post and sends it to the Telegram channel, or only prints it with `--dry-run`. In this task you only test it in dry-run mode.

## Files you may create or change
- `scripts/notify_telegram.py`

## Steps

### `scripts/notify_telegram.py`: spec
- Uses `pyyaml` plus the standard library (`argparse`, `html`, `json`, `os`, `urllib.request`, `pathlib`, `sys`).
- Docstring: `"""Announce a post on Telegram. Run: python scripts/notify_telegram.py --slug <post-folder> [--dry-run]. Needs env TELEGRAM_BOT_TOKEN and TELEGRAM_CHAT_ID unless --dry-run."""`
- Options: `--slug` (required, the post folder name) and `--dry-run` (flag).
- Read `github_username` from `config/owner.yml`.
- Find each language's post file: `<lang>/posts/<slug>/index.qmd`, or `index.ipynb` if the `.qmd` doesn't exist. Read its front matter the same way as `check_pairs.py`. You may copy that function, but **don't import from or change** `check_pairs.py`.
- **Rules:**
  - The English post is missing → stderr `error: en/posts/<slug> not found`, exit **2**.
  - The English post has `draft: true` → stderr `error: English post is still a draft`, exit **2**.
  - The Persian post is missing or `draft: true` → the Persian part is replaced by the single line `نسخهٔ فارسی به‌زودی منتشر می‌شود.`
- **Message** (HTML; escape every title and description with `html.escape`):
  ~~~text
  <b>{fa_title}</b>
  {fa_description}
  🔗 https://{user}.github.io/fa/posts/{slug}/

  <b>{en_title}</b>
  {en_description}
  🔗 https://{user}.github.io/posts/{slug}/
  ~~~
  (When the Persian post isn't ready, the first three lines become the single "به‌زودی" line.)
- `--dry-run`: print `--- DRY RUN: message below ---`, then the message, and exit **0**.
- Otherwise:
  - Read `TELEGRAM_BOT_TOKEN` and `TELEGRAM_CHAT_ID` from the environment. If either is missing → stderr `error: TELEGRAM_BOT_TOKEN and TELEGRAM_CHAT_ID must be set`, exit **2**.
  - POST JSON `{"chat_id": ..., "text": ..., "parse_mode": "HTML", "disable_web_page_preview": false}` to `https://api.telegram.org/bot<TOKEN>/sendMessage` with header `Content-Type: application/json`, timeout 20 s.
  - If the response JSON has `"ok": true` → print `sent to <chat_id>`, exit **0**.
  - Otherwise, or on any exception → stderr `error: Telegram API call failed: <description or exception type>`, exit **1**.
  - **Never print the token or the full request URL.**

## Do NOT
- Don't run it without `--dry-run`. Don't create or read any `.env` file.
