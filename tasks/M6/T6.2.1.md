## Goal
List every **third-party host** the built site loads resources from (scripts, styles, fonts, images, iframes). Any of these may be slow or blocked for readers in Iran. The Reviewer uses the output to decide what to self-host.

## Files you may create or change
- `scripts/audit_external.py`
- `Makefile`

## Steps

### 1. `scripts/audit_external.py`: spec
- Standard library only (`html.parser`, `pathlib`, `re`, `urllib.parse`, `collections`).
- Docstring: `"""List third-party hosts that public/ loads resources from. Run after make build: make audit"""`
- If `public/` doesn't exist → stderr `error: public/ not found - run "make build" first`, exit 1.
- Read `github_username` from `config/owner.yml` **with a simple regex** (no yaml import): `^github_username:\s*"?([^"\n]+)"?`. Own host = `<user>.github.io`.
- For every `public/**/*.html`, parse and collect URLs from:
  - `<script src>`, `<img src>`, `<iframe src>`, `<source src>`, `<video src>`, `<audio src>`
  - `<link href>` when `rel` contains `stylesheet`, `preload`, `modulepreload`, `icon` or `prefetch`
- For every `public/**/*.css` and `public/**/*.js`, collect URLs with the regex `https?://[^\s"'()<>]+` (and `//host/...` in CSS `url(...)`).
- Keep only URLs that start with `http://`, `https://` or `//`, and whose host isn't the own host.
- Output a table sorted by count, descending:
  ```
  host                             count  example_url                                   example_file
  cdn.jsdelivr.net                    42  https://cdn.jsdelivr.net/npm/mathjax@3/...    public/posts/.../index.html
  ```
  Then `audit_external: <H> hosts, <N> references`.
- Exit 0 (it reports and never fails).

### 2. `Makefile`
- Add `audit` to `.PHONY` (before `clean`).
- In `help`, before `make clean`, add: `	@echo "make audit       list third-party hosts used by public/"`
- Before `clean:`, add:
~~~make
audit:
	$(PY) scripts/audit_external.py

~~~

## Verify
```bash
make build && make audit
```
