# T6.1.4 — Telegram link on both home pages

| | |
|---|---|
| Milestone › Checkpoint | M6 Distribution and performance › C6.1 Telegram |
| Who | 🤖 AGENT — level **basic** |
| Depends on | T6.1.3 |
| Time | ~5 min |

## Goal
Add the Telegram channel to the "about" links on both home pages.

## Files you may create or change
- `en/index.qmd`, `fa/index.qmd` (front matter `about: links:` only)

## Steps
1. Read `telegram_channel` from `config/owner.yml`, e.g. `@my_ml_fa`. The URL is `https://t.me/` plus the handle **without** `@`. If it's empty, STOP (BLOCKED).
2. In `en/index.qmd`, add this item at the **end** of `about: links:` (same indentation as the other items):
~~~yaml
    - icon: telegram
      text: Telegram
      href: "https://t.me/<handle-without-@>"
~~~
3. In `fa/index.qmd`, add at the end of `about: links:`:
~~~yaml
    - icon: telegram
      text: "تلگرام"
      href: "https://t.me/<handle-without-@>"
~~~

## Verify
```bash
make build
```
```bash
grep -o 'https://t.me/[A-Za-z0-9_]*' public/index.html public/fa/index.html | sort -u
```

## Done when
- [ ] Both pages contain the same `https://t.me/...` link
