# T6.1.1 — Create the Telegram channel and bot, add secrets

| | |
|---|---|
| Milestone › Checkpoint | M6 Distribution and performance › C6.1 Telegram |
| Who | 👤 HUMAN (Owner) |
| Depends on | M5 gate approved |
| Time | ~15 min |

## Goal
Create a public Telegram channel for post announcements and a bot that can post to it from GitHub Actions. The bot token is a **secret** and never goes into the repo.

## Steps
1. In Telegram, create a **public channel**, e.g. `@my_ml_fa`. Write a short Persian description that links to `https://<username>.github.io/fa/`.
2. Talk to **@BotFather** → `/newbot` → choose a name and username → copy the **token**.
3. Open your channel → Administrators → **Add admin** → choose your bot → allow **Post messages** only.
4. On GitHub: repo → **Settings** → **Secrets and variables** → **Actions** → **New repository secret**:
   - `TELEGRAM_BOT_TOKEN` = the token from step 2
   - `TELEGRAM_CHAT_ID` = your channel handle including `@`, e.g. `@my_ml_fa`
5. Put the channel handle (not the token!) in `config/owner.yml` → `telegram_channel: "@my_ml_fa"` and commit:
   ```bash
   git add config/owner.yml && git commit -m "T6.1.1: telegram channel"
   ```

## Done when
- [ ] The channel exists, the bot is an admin that can post, and both secrets are saved on GitHub
- [ ] The token appears **nowhere** in the repository
