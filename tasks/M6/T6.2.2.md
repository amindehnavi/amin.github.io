## Goal
1. `check_links.py` finds broken **internal** links and resources in `public/`. It runs in CI, so a broken link blocks the deploy.
2. `check_images.py` warns about images over 300 KB, which are slow on Iranian mobile connections. It runs in `make check`.

## Files you may create or change
- `scripts/check_links.py`
- `scripts/check_images.py`
- `Makefile`
- `.github/workflows/publish.yml` (one step added)

## Steps

### 1. `scripts/check_links.py`: spec
- Standard library only.
- Docstring: `"""Find broken internal links in public/. Run after make build: make check-links"""`
- If `public/` doesn't exist → error message and exit 1 (same style as audit).
- For every `public/**/*.html`, collect `a[href]`, `img[src]`, `script[src]`, `link[href]`, `source[src]`, `iframe[src]`.
- **Skip** values that are empty, start with `#`, `mailto:`, `tel:`, `javascript:` or `data:`, or contain `://`, or start with `//` (external).
- Strip the `?query` and `#fragment`, then URL-decode (`urllib.parse.unquote`).
- **Resolve:** a value starting with `/` → `public/` + value. Otherwise → relative to the HTML file's folder.
- **Exists if:** the path is a file; **or** it's a folder containing `index.html`; **or** `path + ".html"` is a file.
- For each missing target, print `BROKEN <html file relative to public/> -> <original value>`.
- Then print `check_links: <F> files, <L> internal links, <B> broken`. Exit **1** if B > 0, otherwise 0.

### 2. `scripts/check_images.py`: spec
- Standard library only.
- Docstring: `"""Warn about images larger than 300 KB. Run: make check"""`
- Scan `shared/images/`, `en/posts/`, `fa/posts/` recursively for `.png .jpg .jpeg .webp .gif` files (case-insensitive).
- For each file over 300 × 1024 bytes, print `WARN <path> is <size in KB, rounded> KB (limit 300 KB)`.
- Print `check_images: <N> images, <W> too large`. Exit 0. With `--strict`, exit 1 if W > 0.

### 3. `Makefile`
- Add `check-links` to `.PHONY`.
- Add to `help`: `	@echo "make check-links check internal links in public/ (after build)"`
- Change the `check` recipe to (TABs):
~~~make
check: sync
	$(PY) scripts/check_pairs.py
	$(PY) scripts/lint_fa.py
	$(PY) scripts/check_images.py
~~~
- Before `clean:`, add:
~~~make
check-links:
	$(PY) scripts/check_links.py

~~~

### 4. `.github/workflows/publish.yml`
Directly after the `Build both sites` step, add this step (same indentation as the other steps):
~~~yaml
      - name: Check internal links
        run: python scripts/check_links.py
~~~

## Verify

make build && make check-links; echo "exit=$?"
```

mkdir -p public/zz && printf '<a href="/does-not-exist/">x</a>' > public/zz/index.html && (.venv/bin/python scripts/check_links.py; echo "exit=$?"); rm -rf public/zz
```
```bash

```
