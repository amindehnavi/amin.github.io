# R1 — Scaffold a new post (both languages)

| | |
|---|---|
| Milestone | M8 Operating mode (recurring) |
| Who | 🤖 AGENT — level **basic** |
| Inputs given by the Owner in the prompt | `SLUG` (short slug, e.g. `self-attention`), `TITLE_EN`, `TITLE_FA` (optional), `SERIES` (optional), `ORDER` (optional, required if SERIES is given) |
| Time | ~5 min |

## Goal
Create the English and Persian post files from the templates with one command.

## Files you may create or change
- `en/posts/<YYYY-MM>-<SLUG>/index.qmd`
- `fa/posts/<YYYY-MM>-<SLUG>/index.qmd`

## Steps
1. Build the command from the inputs. Leave out the options that weren't given:
```bash
make new-post ARGS='--slug <SLUG> --title-en "<TITLE_EN>" --title-fa "<TITLE_FA>" --series <SERIES> --series-order <ORDER>'
```
2. Run it. If it fails, STOP (BLOCKED) and paste the error. Don't create the files by hand.

## Verify
```bash
git status --short
```
```bash
head -14 en/posts/*-<SLUG>/index.qmd
```

## Done when
- [ ] Exactly two new files exist, with the same folder name
- [ ] The report states the **full folder name** (e.g. `2026-12-self-attention`). The Owner uses it as SLUG in R3, R4 and R6

## Commit message
`R1: Scaffold post <full folder name>`
