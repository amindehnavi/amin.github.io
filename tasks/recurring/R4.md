# R4 — Persian draft of a post

| | |
|---|---|
| Milestone | M8 Operating mode (recurring) |
| Who | 🤖 AGENT — level **standard** (strong Persian required) |
| Inputs given by the Owner in the prompt | `SLUG` = full post folder name |
| Time | ~30–60 min |

## Goal
Translate the finished English post into a Persian draft, following `prompts/translate_en_to_fa.md` exactly.

## Files you may create or change
- `fa/posts/<SLUG>/index.qmd` (replace its whole content)
- other files in `fa/posts/<SLUG>/`: copy any images or data files from `en/posts/<SLUG>/` **unchanged** (images are shared)
- generated files under `fa/_freeze/`

## Steps
1. Read `prompts/translate_en_to_fa.md` completely. It is your main instruction for this task.
2. Read `en/posts/<SLUG>/index.qmd` and `shared/data/glossary.yml`.
3. Copy every non-`.qmd` file from `en/posts/<SLUG>/` (images, csv, …) to `fa/posts/<SLUG>/`.
4. Write the Persian post into `fa/posts/<SLUG>/index.qmd`, keeping `draft: true`.
5. Do the prompt's **Final self-check**.

## Verify
```bash
diff <(grep -c '^```' en/posts/<SLUG>/index.qmd) <(grep -c '^```' fa/posts/<SLUG>/index.qmd) && echo "code fences equal"
```
```bash
diff <(grep -o '\$' en/posts/<SLUG>/index.qmd | wc -l) <(grep -o '\$' fa/posts/<SLUG>/index.qmd | wc -l) && echo "dollar signs equal"
```
```bash
grep -n "^draft:" fa/posts/<SLUG>/index.qmd
```
```bash
make render-fa 2>&1 | tail -20
```
```bash
.venv/bin/python scripts/lint_fa.py fa/posts/<SLUG>/index.qmd; echo "exit=$?"
```
```bash
.venv/bin/python scripts/check_pairs.py; echo "exit=$?"
```

- [ ] `code fences equal` and `dollar signs equal` are printed
