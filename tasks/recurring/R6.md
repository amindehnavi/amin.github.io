# R6 — Publish checks for a post

| | |
|---|---|
| Milestone | M8 Operating mode (recurring) |
| Who | 🤖 AGENT — level **basic** |
| Inputs given by the Owner in the prompt | `SLUG` = full post folder name |
| Time | ~10 min |

## Goal
Flip the post to published in both languages and prove that everything still builds and passes.

## Files you may create or change
- `en/posts/<SLUG>/index.qmd`, `fa/posts/<SLUG>/index.qmd` (the `draft:` line only)

## Steps
1. In both files, change `draft: true` to `draft: false`.
2. Run the checks below.

## Verify
```bash
make clean && make build
```
```bash
make check; echo "exit=$?"
```
```bash
make check-links; echo "exit=$?"
```
```bash
grep -n "TODO(owner)\|TRANSLATOR NOTE" en/posts/<SLUG>/index.qmd fa/posts/<SLUG>/index.qmd; echo "exit=$?"
```
```bash
grep -c "<SLUG>" public/blog.html public/fa/blog.html public/blog.xml public/fa/blog.xml
```

## Done when
- [ ] build, check and check-links all succeed (`exit=0`)
- [ ] There are no TODO or TRANSLATOR NOTE lines (`exit=1`)
- [ ] The post appears in both listings and both feeds (count ≥ 1 each)
- [ ] If anything fails: set both files back to `draft: true`, don't commit, and report BLOCKED
