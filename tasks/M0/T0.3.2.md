# T0.3.2 — Gather content inputs (due before M2)

| | |
|---|---|
| Milestone › Checkpoint | M0 Prerequisites › C0 (you may finish this any time before M2 starts) |
| Who | 👤 HUMAN (Owner) |
| Depends on | T0.1.2 |
| Time | 1–2 h (writing) |

## Goal
Write the personal content that agents will turn into pages. Agents must **never** write this content themselves. Everything goes in `content-inputs/`.

## Files to create

### 1. `content-inputs/bio.en.md`
80–150 words, first person, plain Markdown, no headings. Cover who you are, what you work on, why you write this blog (helping Persian-speaking learners), and what readers can expect.

### 2. `content-inputs/profile.jpg`
A square photo, at least 400×400 px and under 300 KB.

### 3. `content-inputs/projects.yml`
3–5 projects, in this exact format (leave fields you don't have as `""`):
```yaml
- slug: "defect-detection"            # lowercase-with-dashes, unique
  title_en: "Surface Defect Detection"
  title_fa: ""                        # optional; agent drafts it if empty
  summary_en: "One sentence: what it does and the result."
  summary_fa: ""                      # optional; agent drafts it if empty
  year: 2025
  tags: [computer-vision, pytorch]
  url: "https://github.com/..."       # repo or demo link (required)
  image: "defect-detection.png"       # file you put in content-inputs/projects/ (optional)
```
Put the project images in `content-inputs/projects/`. Use PNG or JPG, about 1200×675, under 300 KB.

### 4. `content-inputs/publications.yml` (optional; skip if none)
```yaml
- title: "Paper title exactly as published"
  authors: "A. Author, B. Author"
  venue: "CVPR 2025"
  date: 2025-06-01
  url: "https://..."
```

### 5. `content-inputs/talks.yml` (optional; skip if none)
```yaml
- title: "Talk or course title"
  event: "Event name, City"
  date: 2025-03-10
  url: ""              # slides/video link, or ""
```

### 6. `content-inputs/cv.md`
Short CV in Markdown with these exact headings: `## Experience`, `## Education`, `## Skills`. Use bullet points, and newest first.

### 7. `content-inputs/cv.pdf`
Your full CV as a PDF, in English.

## Then
```bash
git add content-inputs && git commit -m "T0.3.2: content inputs" && git push
```

## Done when
- [ ] Files 1, 2, 3, 6 and 7 exist (4 and 5 only if you have the items)
- [ ] Nothing in them is something you're unwilling to publish
