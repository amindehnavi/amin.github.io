# T0.1.1 — Create the GitHub repository and enable Pages

| | |
|---|---|
| Milestone › Checkpoint | M0 Prerequisites › C0 |
| Who | 👤 HUMAN (Owner) |
| Depends on | nothing |
| Time | ~10 min |

## Goal
Create an empty public repository named exactly `<your-github-username>.github.io`, and set GitHub Pages to deploy from GitHub Actions.

## Steps
1. Log in to GitHub. Note your username exactly, in lowercase. It's used as `github_username` in T0.3.1.
2. Click **New repository**:
   - Name: `<username>.github.io`, e.g. `amin-ml.github.io`
   - Visibility: **Public**
   - Do **not** add a README, .gitignore or license, so the repo stays empty
3. Open the repo → **Settings** → **Pages**:
   - **Source:** choose **GitHub Actions**, not "Deploy from a branch"
4. Open the repo → **Settings** → **General** → **Features**: tick **Discussions**. We'll use it for comments in M4.

## Done when
- [x] `https://github.com/<username>/<username>.github.io` exists, is public and is empty
- [x] Pages source = GitHub Actions
- [x] Discussions are enabled
