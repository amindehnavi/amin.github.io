# T0.1.2 — Initialize the local git repo and first push

| | |
|---|---|
| Milestone › Checkpoint | M0 Prerequisites › C0 |
| Who | 👤 HUMAN (Owner) |
| Depends on | T0.1.1 |
| Time | ~5 min |

## Goal
Turn `~/Projects/personal-website` (which already contains PLAN.md, ROADMAP.md and tasks/) into a git repository connected to GitHub.

## Steps
Run these one at a time, replacing `<username>`:

```bash
cd ~/Projects/personal-website
```
```bash
git init -b main
```
```bash
git remote add origin https://github.com/<username>/<username>.github.io.git
```
```bash
git add PLAN.md ROADMAP.md tasks
```
```bash
git commit -m "Add plan, roadmap and task files"
```
```bash
git push -u origin main
```

> If `git push` asks for a password, GitHub needs a Personal Access Token or the GitHub CLI (`gh auth login`), not your account password.

## Done when
- [ ] `git remote -v` shows the GitHub URL
- [ ] PLAN.md, ROADMAP.md and tasks/ are visible on GitHub

> After all of M0 is done, ask the Reviewer to "Review checkpoint C0". On PASS, run `git tag approved/C0 && git push --tags`. That tag is the base for every later diff.
