# T0.2.2 — Choose and set up your agent tool

| | |
|---|---|
| Milestone › Checkpoint | M0 Prerequisites › C0 |
| Who | 👤 HUMAN (Owner) |
| Depends on | T0.2.1 |
| Time | ~15 min |

## Goal
Choose a coding-agent tool that can **read and write files and run shell commands** in `~/Projects/personal-website`. For example: Claude Code with a cheaper model, Aider, Cursor agent, Codex CLI, or anything similar.

## Steps
1. Install or open the tool and point it at `~/Projects/personal-website`.
2. Choose two model settings:
   - **basic** tasks → the cheapest model that can follow instructions and run commands
   - **standard** tasks → a mid-range model, and for Persian tasks one that writes good Persian
3. Allow it to run shell commands in this folder only. Don't give it GitHub credentials or push rights.
4. Dry run: start a session and paste
   ```text
   Read tasks/AGENT_RULES.md and summarise the 8 sections in one line each. Do not change any file.
   ```
   Check that the summary is correct. If it's badly wrong, choose a stronger model for "basic".

## Done when
- [ ] The agent tool opens in the project folder and can run `ls`
- [ ] The dry run summary is correct and the agent changed no files (`git status` is clean)
