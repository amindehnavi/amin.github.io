# T0.2.1 — Install local tools and record the Quarto version

| | |
|---|---|
| Milestone › Checkpoint | M0 Prerequisites › C0 |

| Depends on | T0.1.2 |
| Time | ~20 min |

## Goal
Get the tools on your Mac that agents need: Quarto, Python 3.11+, make and git. Then write the exact Quarto version to `.quarto-version`, so CI uses the same one.

## Steps
1. **Quarto:** download the latest *stable* macOS installer from https://quarto.org/docs/get-started/ and install it.
2. **Command-line tools** (gives `make` and `git`), skip if already installed:
   ```bash
   xcode-select --install
   ```
3. **Python 3.11 or newer.** Check with:
   ```bash
   python3 --version
   ```
   If it's older than 3.11, install it from https://www.python.org/downloads/ or with your usual tool (pyenv/conda are fine).
4. Check everything:
   ```bash
   quarto --version && python3 --version && make --version | head -1 && git --version
   ```
5. Record the Quarto version (only the number, e.g. `1.8.25`):
   ```bash
   cd ~/Projects/personal-website && quarto --version > .quarto-version && cat .quarto-version
   ```
6. Commit it:
   ```bash
   git add .quarto-version && git commit -m "T0.2.1: record Quarto version" && git push
   ```

## Done when
- [ ] All four tools print a version
- [ ] `.quarto-version` contains a single version number and is pushed
