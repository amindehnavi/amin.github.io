# T4.3.2 — Add the analytics snippet

| | |
|---|---|
| Milestone › Checkpoint | M4 Community, SEO and analytics › C4.3 Analytics |
| Who | 🤖 AGENT — level **basic** |
| Depends on | T4.3.1 |
| Time | ~5 min |

## Goal
Load GoatCounter on every page of both sites.

## Files you may create or change
- `shared/js/analytics.html`
- `en/_quarto.yml`, `fa/_quarto.yml`

## Steps
1. `shared/js/analytics.html`, **exact content** (fill in the placeholder):
~~~html
<script data-goatcounter="https://{{GOATCOUNTER_CODE}}.goatcounter.com/count" async src="https://gc.zgo.at/count.js"></script>
~~~
2. In **both** configs, under `format:` → `html:`, add this line directly **after** the `include-after-body:` line (4-space indentation):
~~~yaml
    include-in-header: assets/js/analytics.html
~~~

## Verify
```bash
make build
```
```bash
grep -c 'goatcounter' public/index.html public/fa/index.html public/posts/2026-10-hello-world/index.html
```
```bash
grep -c "{{" shared/js/analytics.html; echo "exit=$?"
```
