# T4.1.2 — Enable Giscus comments on posts (EN + FA)

| | |
|---|---|
| Milestone › Checkpoint | M4 Community, SEO and analytics › C4.1 Comments |
| Who | 🤖 AGENT — level **basic** |
| Depends on | T4.1.1 |
| Time | ~10 min |

## Goal
Show a comment box under every post (not on other pages), with the interface in the page's language. English and Persian comments go to separate discussion categories.

## Files you may create or change
- `en/posts/_metadata.yml`
- `fa/posts/_metadata.yml`

## Steps
1. Append to the end of `en/posts/_metadata.yml` (**exact content**, with placeholders filled in):
~~~yaml
comments:
  giscus:
    repo: "{{GITHUB_USERNAME}}/{{GITHUB_USERNAME}}.github.io"
    repo-id: "{{GISCUS_REPO_ID}}"
    category: "Comments (English)"
    category-id: "{{GISCUS_CATEGORY_ID_EN}}"
    mapping: pathname
    reactions-enabled: true
    loading: lazy
    input-position: top
    theme:
      light: light
      dark: dark
    language: en
~~~
2. Append to the end of `fa/posts/_metadata.yml` (**exact content**):
~~~yaml
comments:
  giscus:
    repo: "{{GITHUB_USERNAME}}/{{GITHUB_USERNAME}}.github.io"
    repo-id: "{{GISCUS_REPO_ID}}"
    category: "Comments (Persian)"
    category-id: "{{GISCUS_CATEGORY_ID_FA}}"
    mapping: pathname
    reactions-enabled: true
    loading: lazy
    input-position: top
    theme:
      light: light
      dark: dark
    language: fa
~~~

## Do NOT
- Don't put comments in `_quarto.yml` (that would add them to every page).
