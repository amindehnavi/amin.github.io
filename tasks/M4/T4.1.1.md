# T4.1.1 — Set up GitHub Discussions and Giscus

| | |
|---|---|
| Milestone › Checkpoint | M4 Community, SEO and analytics › C4.1 Comments |
| Who | 👤 HUMAN (Owner) |
| Depends on | M3 gate approved |
| Time | ~15 min |

## Goal
Prepare comments: readers comment with their GitHub account, and the comments are stored as GitHub Discussions in your repo. Get the IDs that the agent needs.

## Steps
1. Make sure Discussions are on: repo → **Settings** → **General** → **Features** → ✓ Discussions.
2. Repo → **Discussions** → ✏️ (edit categories) → **New category**, twice:
   - Name `Comments (English)`, format **Announcement**
   - Name `Comments (Persian)`, format **Announcement**
   (Announcement means only giscus or you can open new threads, while anyone can reply.)
3. Install the giscus app for **only this repository**: https://github.com/apps/giscus → Install → *Only select repositories* → `<username>.github.io`.
4. Open https://giscus.app:
   - Repository: `<username>/<username>.github.io` (it should say the repo meets all criteria)
   - Page ↔ Discussions mapping: **pathname**
   - Discussion category: `Comments (English)`
   - Scroll down to the generated `<script>`. Copy `data-repo-id` and `data-category-id`.
   - Switch the category to `Comments (Persian)` and copy that `data-category-id` too.
5. Put the values in `config/owner.yml`: `giscus_repo_id`, `giscus_category_id_en`, `giscus_category_id_fa`.
6. Commit:
   ```bash
   git add config/owner.yml && git commit -m "T4.1.1: giscus ids"
   ```

## Done when
- [ ] Both categories exist, giscus is installed, and all 3 IDs are in `config/owner.yml`
