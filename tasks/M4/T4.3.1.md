# T4.3.1 — Create a GoatCounter account

| | |
|---|---|
| Milestone › Checkpoint | M4 Community, SEO and analytics › C4.3 Analytics |
| Who | 👤 HUMAN (Owner) |
| Depends on | C4.2 approved |
| Time | ~5 min |

## Goal
Set up free, cookie-free, privacy-friendly page-view counting.

## Steps
1. Sign up at https://www.goatcounter.com. Choose a **code**, for example `amin-ml`. Your dashboard will be `https://<code>.goatcounter.com`.
2. Put the code in `config/owner.yml` → `goatcounter_code: "<code>"`.
3. Commit:
   ```bash
   git add config/owner.yml && git commit -m "T4.3.1: goatcounter code"
   ```

## Done when
- [ ] You can log in to your GoatCounter dashboard, and the code is in `config/owner.yml`
