## Goal
Make links to the site look good when shared on Telegram, LinkedIn or X (a preview image, title and description), and help search engines find both sitemaps.

## Files you may create or change
- `scripts/make_social_card.py`
- `shared/images/social-card.png` (generated by the script; commit it)
- `en/robots.txt`
- `en/_quarto.yml`, `fa/_quarto.yml`

## Steps

### 1. `scripts/make_social_card.py`: spec
- Uses `matplotlib` and `pyyaml` (already in `.venv`).
- Docstring: `"""Generate shared/images/social-card.png (1200x630) from config/owner.yml. Run: .venv/bin/python scripts/make_social_card.py"""`
- Reads `config/owner.yml` (UTF-8) and uses `name_en`, `tagline_en`, `github_username`. **English only**, because matplotlib can't shape Persian text.
- Figure: `figsize=(12, 6.3)`, `dpi=100` (→ 1200×630 px), background `#3b5bdb`, no axes (`ax.axis("off")`, and the axes cover the whole figure: `fig.add_axes([0, 0, 1, 1])`).
- Text, all white `#ffffff`, left-aligned at x = 0.07 (axes coordinates):
  - `name_en`, y = 0.60, fontsize 60, bold
  - `tagline_en`, y = 0.45, fontsize 26, alpha 0.9
  - `<github_username>.github.io`, y = 0.12, fontsize 22, alpha 0.8
- Save to `shared/images/social-card.png` with `facecolor` = the background colour. Don't use `bbox_inches="tight"`, since it would change the size.
- Print `wrote shared/images/social-card.png`.

### 2. `en/robots.txt`: exact content
~~~text
User-agent: *
Allow: /

Sitemap: https://{{GITHUB_USERNAME}}.github.io/sitemap.xml
Sitemap: https://{{GITHUB_USERNAME}}.github.io/fa/sitemap.xml
~~~

### 3. `en/_quarto.yml`
- Under `project:` → `resources:`, add the item `- robots.txt` after `- assets/**`.
- Under `website:`, directly after the `favicon:` line, insert:
~~~yaml
  image: assets/images/social-card.png
  open-graph:
    locale: en_US
  twitter-card: true
~~~

### 4. `fa/_quarto.yml`
- Under `website:`, directly after the `favicon:` line, insert:
~~~yaml
  image: assets/images/social-card.png
  open-graph:
    locale: fa_IR
  twitter-card: true
~~~
