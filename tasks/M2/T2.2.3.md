## Goal
Make the Persian bio sound like **you**.

## Steps
1. Run `make preview-fa` and open the URL it prints.
2. Edit the text between `::: {#about-block}` and `[خواندن نوشته‌ها ←]` in `fa/index.qmd`. The preview refreshes on save.
3. Check: natural tone, correct نیم‌فاصله, ی/ک, and English names wrapped in `[...]{.ltr}`.
4. Commit:
   ```bash
   git add fa/index.qmd && git commit -m "T2.2.3: edit Persian bio"
   ```
5. Then ask the Reviewer: **"Review checkpoint C2.2"**.
