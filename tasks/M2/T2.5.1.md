## Goal
Create a CV page in each language with a PDF download button, plus one 404 page for the whole site.

## Background (read only)
- GitHub Pages serves only the root `/404.html` for every missing URL, so there's a single bilingual 404 page in `en/`.
- The PDF CV is in English. The Persian CV page is a Persian summary that links to the English PDF.

## Inputs
- `content-inputs/cv.md` (headings `## Experience`, `## Education`, `## Skills`)
- `content-inputs/cv.pdf`

## Files you may create or change
- `shared/files/cv.pdf` (copy)
- `en/cv.qmd`
- `fa/cv.qmd`
- `en/404.qmd`

## Steps
1. Copy `content-inputs/cv.pdf` to `shared/files/cv.pdf`. If either input is missing, STOP (BLOCKED).
2. `en/cv.qmd`: the front matter and button below, then the **full content of `content-inputs/cv.md`, unchanged**:
~~~markdown
---
title: "CV"
toc: false
---

[Download the full CV (PDF)](assets/files/cv.pdf){.btn .btn-primary}

~~~
3. `fa/cv.qmd`: the front matter and button below, then a **faithful Persian translation** of `content-inputs/cv.md`:
   - Headings become exactly `## سوابق کاری`, `## تحصیلات`, `## مهارت‌ها`.
   - Keep names of companies, universities, degrees' official names, tools and libraries in English, wrapped like `[PyTorch]{.ltr}`.
   - Keep dates and numbers as they are. Add no facts.
~~~markdown
---
title: "رزومه"
toc: false
---

[دریافت رزومهٔ کامل (PDF، به انگلیسی)](assets/files/cv.pdf){.btn .btn-primary}

~~~
4. `en/404.qmd`, **exact content**:
~~~markdown
---
title: "Page not found"
toc: false
---

Sorry, this page doesn't exist. Go to the [home page](index.qmd) or read the [blog](blog.qmd).

::: {dir="rtl" lang="fa"}
متأسفیم، این صفحه وجود ندارد. به [صفحهٔ اصلی فارسی](/fa/) بروید یا [نوشته‌ها](/fa/blog.html) را بخوانید.
:::
~~~

## Do NOT
- Don't create `fa/404.qmd`.
- Don't change the navbar (that's T2.5.2).
