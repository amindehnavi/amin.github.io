# T2.2.1 — English home/about page

| Time | ~15 min |

## Goal
Replace the placeholder English home page with an "about" page: photo, bio, social links, and the 3 latest posts.

## Inputs
- `config/owner.yml`
- `content-inputs/bio.en.md` (the bio text; copy it **exactly**, never rewrite it)
- `content-inputs/profile.jpg`

## Files you may create or change
- `shared/images/profile.jpg` (copied from `content-inputs/profile.jpg`)
- `en/index.qmd`

## Steps
1. Copy `content-inputs/profile.jpg` to `shared/images/profile.jpg`. If the input file is missing, STOP (BLOCKED).
2. Replace **all** of `en/index.qmd` with the content below, then:
   - replace placeholders from `config/owner.yml`
   - **Special rule for optional links:** if `linkedin_url`, `scholar_url` or `x_url` is empty (`""`), delete that whole link item (its 3 lines: `- icon`, `text`, `href`). This is an exception to the BLOCKED rule.
   - replace the line `BIO_TEXT_HERE` with the full content of `content-inputs/bio.en.md`, unchanged
~~~markdown
---
title: "{{NAME_EN}}"
subtitle: "{{TAGLINE_EN}}"
image: assets/images/profile.jpg
image-alt: "Photo of {{NAME_EN}}"
toc: false
about:
  template: trestles
  image-shape: round
  image-width: 14em
  id: about-block
  links:
    - icon: github
      text: GitHub
      href: "https://github.com/{{GITHUB_USERNAME}}"
    - icon: linkedin
      text: LinkedIn
      href: "{{LINKEDIN_URL}}"
    - icon: mortarboard-fill
      text: Scholar
      href: "{{SCHOLAR_URL}}"
    - icon: twitter-x
      text: X
      href: "{{X_URL}}"
    - icon: envelope
      text: Email
      href: "mailto:{{EMAIL}}"
listing:
  id: latest-posts
  contents: posts
  sort: "date desc"
  type: default
  max-items: 3
  feed: false
  fields: [date, title, description]
---

::: {#about-block}
BIO_TEXT_HERE

[Read the blog →](blog.qmd)
:::

## Latest posts

::: {#latest-posts}
:::
~~~

## Do NOT
- Don't rewrite, shorten or "improve" the bio.
- Don't add links that aren't listed above.
