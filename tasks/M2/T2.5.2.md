| | |
|---|---|

## Goal
Add the new pages to the navbar of both sites.

## Files you may create or change
- `en/_quarto.yml` (only the `navbar: left:` list)
- `fa/_quarto.yml` (only the `navbar: left:` list)

## Steps
1. Check whether `en/publications.qmd` exists (T2.4.1 may have been skipped).
2. In `en/_quarto.yml`, replace the whole `left:` list under `navbar:` with exactly this. **If `en/publications.qmd` doesn't exist, leave out the two Publications lines.**
~~~yaml
    left:
      - href: index.qmd
        text: "Home"
      - href: blog.qmd
        text: "Blog"
      - href: projects.qmd
        text: "Projects"
      - href: publications.qmd
        text: "Publications"
      - href: cv.qmd
        text: "CV"
~~~
3. In `fa/_quarto.yml`, replace the whole `left:` list under `navbar:` with exactly this, applying the same rule to the publications lines:
~~~yaml
    left:
      - href: index.qmd
        text: "خانه"
      - href: blog.qmd
        text: "نوشته‌ها"
      - href: projects.qmd
        text: "پروژه‌ها"
      - href: publications.qmd
        text: "مقالات و ارائه‌ها"
      - href: cv.qmd
        text: "رزومه"
~~~

## Do NOT
- Don't change the `right:` list or anything else.

## Verify
```bash
make build
```
```bash
grep -o 'href="[^"]*\(projects\|publications\|cv\)\.html"' public/index.html | sort -u
```
```bash
grep -o 'href="[^"]*\(projects\|publications\|cv\)\.html"' public/fa/index.html | sort -u
```

## Done when
- [ ] `make build` succeeds
- [ ] Both outputs list `projects.html` and `cv.html`, plus `publications.html` if that page exists
