# T2.4.1 — Publications and talks pages (EN + FA)

| | |
|---|---|
| Milestone › Checkpoint | M2 Design and identity › C2.4 Publications and talks |
| Who | 🤖 AGENT — level **standard** |
| Depends on | C2.3 approved |
| Time | ~20 min |

## Goal
Create a "Publications & Talks" page in each language, with tables generated from data files.

## Inputs
- `content-inputs/publications.yml` (optional): items with `title, authors, venue, date, url`
- `content-inputs/talks.yml` (optional): items with `title, event, date, url`

## Files you may create or change
- `en/data/publications.yml`, `fa/data/publications.yml`
- `en/data/talks.yml`, `fa/data/talks.yml`
- `en/publications.qmd`, `fa/publications.qmd`

## Steps
**Case check first:**
- If **neither** input file exists (or both are empty), create nothing. Write the report with status DONE and the line `SKIPPED: no publications or talks`, then commit only the report.
- If only **one** exists, do the steps for that one only, and leave out the other listing **and its section** from both pages.

1. From `content-inputs/publications.yml`, create `en/data/publications.yml`. Keep the input order and use this shape per item:
~~~yaml
- title: "<title>"
  author: "<authors>"
  description: "<venue>"
  date: <date>
  path: "<url>"
~~~
2. From `content-inputs/talks.yml`, create `en/data/talks.yml`, per item (leave out `path` if `url` is empty):
~~~yaml
- title: "<title>"
  description: "<event>"
  date: <date>
  path: "<url>"
~~~
3. Copy both data files unchanged to `fa/data/`. Paper and talk titles stay in their original language.
4. `en/publications.qmd`, **exact content**:
~~~markdown
---
title: "Publications & Talks"
toc: false
listing:
  - id: publications
    contents: data/publications.yml
    type: table
    sort: "date desc"
    fields: [date, title, author, description]
    field-display-names:
      description: "Venue"
    filter-ui: false
    sort-ui: false
  - id: talks
    contents: data/talks.yml
    type: table
    sort: "date desc"
    fields: [date, title, description]
    field-display-names:
      description: "Event"
    filter-ui: false
    sort-ui: false
page-layout: full
title-block-banner: false
---

## Publications

::: {#publications}
:::

## Talks & teaching

::: {#talks}
:::
~~~
5. `fa/publications.qmd`, **exact content**:
~~~markdown
---
title: "مقالات و ارائه‌ها"
toc: false
listing:
  - id: publications
    contents: data/publications.yml
    type: table
    sort: "date desc"
    fields: [date, title, author, description]
    field-display-names:
      description: "محل انتشار"
    filter-ui: false
    sort-ui: false
  - id: talks
    contents: data/talks.yml
    type: table
    sort: "date desc"
    fields: [date, title, description]
    field-display-names:
      description: "رویداد"
    filter-ui: false
    sort-ui: false
page-layout: full
title-block-banner: false
---

## مقالات

::: {#publications}
:::

## ارائه‌ها و تدریس

::: {#talks}
:::
~~~

## Do NOT
- Don't add items that aren't in the inputs.
- Don't change the navbar (that's T2.5.2).
