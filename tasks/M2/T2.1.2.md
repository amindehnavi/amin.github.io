# T2.1.2 — Favicon and page footer

| | |
|---|---|
| Milestone › Checkpoint | M2 Design and identity › C2.1 Theme |
| Who | 🤖 AGENT — level **basic** |
| Depends on | T2.1.1 |
| Time | ~10 min |

## Goal
Add a simple monogram favicon (an SVG of the owner's initials) and a footer with copyright, license, GitHub and RSS links, in both languages.

## Files you may create or change
- `shared/images/favicon.svg`
- `en/_quarto.yml`
- `fa/_quarto.yml`

## Steps
1. Work out the **initials**: the first letter of the first word and the first letter of the last word of `name_en` in `config/owner.yml`, uppercase. For example, "Amin Mardehnavi" → `AM`. If `name_en` is a single word, use its first letter only.
2. Create `shared/images/favicon.svg` with this **exact content**, replacing `XX` with the initials:
~~~xml
<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 64 64">
  <rect width="64" height="64" rx="14" fill="#3b5bdb"/>
  <text x="32" y="42" font-family="system-ui, -apple-system, Segoe UI, sans-serif" font-size="28" font-weight="700" text-anchor="middle" fill="#ffffff">XX</text>
</svg>
~~~
3. In `en/_quarto.yml`, directly **after** the line `  draft-mode: gone`, insert exactly:
~~~yaml
  favicon: assets/images/favicon.svg
  page-footer:
    left: "© {{COPYRIGHT_YEAR}} {{NAME_EN}} · Text licensed {{CONTENT_LICENSE}}"
    right:
      - icon: github
        href: "https://github.com/{{GITHUB_USERNAME}}"
        aria-label: "GitHub"
      - icon: rss
        href: blog.xml
        aria-label: "RSS feed"
~~~
4. In `fa/_quarto.yml`, directly **after** the line `  draft-mode: gone`, insert exactly:
~~~yaml
  favicon: assets/images/favicon.svg
  page-footer:
    left: "© {{COPYRIGHT_YEAR}} {{NAME_FA}} · متن‌ها با مجوز {{CONTENT_LICENSE}}"
    right:
      - icon: github
        href: "https://github.com/{{GITHUB_USERNAME}}"
        aria-label: "گیت‌هاب"
      - icon: rss
        href: blog.xml
        aria-label: "خوراک RSS"
~~~

## Do NOT
- Don't change any other config line.
