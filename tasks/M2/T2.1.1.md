# T2.1.1 — Light and dark theme

| | |
|---|---|
| Milestone › Checkpoint | M2 Design and identity › C2.1 Theme |
| Who | 🤖 AGENT — level **basic** |
| Depends on | M1 gate approved |
| Time | ~10 min |

## Goal
Add a shared color and typography theme with light and dark modes for both sites. Quarto shows a light/dark toggle automatically when both are defined.

## Files you may create or change
- `shared/styles/base.scss`
- `shared/styles/dark.scss`
- `en/_quarto.yml` (only the `theme` lines)
- `fa/_quarto.yml` (only the `theme` lines)

## Steps
1. `shared/styles/base.scss`, **exact content**:
~~~scss
/*-- scss:defaults --*/
$primary: #3b5bdb;
$body-bg: #ffffff;
$body-color: #1f2328;
$link-color: #3b5bdb;
$navbar-bg: #ffffff;
$navbar-fg: #1f2328;
$navbar-hl: #3b5bdb;
$footer-bg: #ffffff;
$code-color: #a61e4d;
$font-family-sans-serif: system-ui, -apple-system, "Segoe UI", Roboto, "Helvetica Neue", Arial, sans-serif;
$font-family-monospace: ui-monospace, SFMono-Regular, Menlo, Consolas, "Liberation Mono", monospace;
$font-size-root: 17px;
$line-height-base: 1.7;

/*-- scss:rules --*/
h1, h2, h3, h4 {
  font-weight: 700;
}
.navbar {
  border-bottom: 1px solid rgba(0, 0, 0, 0.08);
}
.quarto-title .subtitle {
  opacity: 0.8;
}
.cell-output-display img,
figure img {
  border-radius: 6px;
}
~~~
2. `shared/styles/dark.scss`, **exact content**:
~~~scss
/*-- scss:defaults --*/
$primary: #7aa2ff;
$body-bg: #0f1419;
$body-color: #e6edf3;
$link-color: #7aa2ff;
$navbar-bg: #0f1419;
$navbar-fg: #e6edf3;
$navbar-hl: #7aa2ff;
$footer-bg: #0f1419;
$code-color: #ff8fab;
$code-block-bg: #161b22;

/*-- scss:rules --*/
.navbar {
  border-bottom: 1px solid rgba(255, 255, 255, 0.08);
}
~~~
3. In `en/_quarto.yml`, replace the line `    theme: cosmo` with exactly:
~~~yaml
    theme:
      light: [cosmo, assets/styles/base.scss]
      dark: [cosmo, assets/styles/base.scss, assets/styles/dark.scss]
~~~
4. In `fa/_quarto.yml`, replace the line `    theme: [cosmo, assets/styles/rtl.scss]` with exactly the lines below. `rtl.scss` stays **last**, so the Persian font wins:
~~~yaml
    theme:
      light: [cosmo, assets/styles/base.scss, assets/styles/rtl.scss]
      dark: [cosmo, assets/styles/base.scss, assets/styles/dark.scss, assets/styles/rtl.scss]
~~~

## Do NOT
- Don't change any other config line.
