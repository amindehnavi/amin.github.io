# T2.3.1 — Projects pages (EN + FA) from `content-inputs/projects.yml`

| | |
|---|---|
| Milestone › Checkpoint | M2 Design and identity › C2.3 Projects |
| Who | 🤖 AGENT — level **standard** (writes some Persian) |
| Depends on | C2.2 approved |
| Time | ~25 min |

## Goal
Create a "Projects" page in each language: a grid of cards built from a small data file. Each card shows an image, title, one-line summary and tags, and links to the project URL.

## Inputs
- `content-inputs/projects.yml`: list of projects with keys `slug, title_en, title_fa, summary_en, summary_fa, year, tags, url, image`
- `content-inputs/projects/` (project images)

## Files you may create or change
- `shared/images/projects/<image files>` (copies)
- `en/data/projects.yml`
- `fa/data/projects.yml`
- `en/projects.qmd`
- `fa/projects.qmd`

## Steps
1. If `content-inputs/projects.yml` is missing or empty, STOP (BLOCKED).
2. For every project with a non-empty `image`, copy `content-inputs/projects/<image>` to `shared/images/projects/<image>`. If an image file is missing, leave the `image` line out for that project and list it in the report.
3. Create `en/data/projects.yml`. Write one item per project, **in the same order** as the input:
~~~yaml
- title: "<title_en>"
  description: "<summary_en>"
  date: "<year>-01-01"
  categories: [<tags, comma-separated, unchanged>]
  path: "<url>"
  image: "assets/images/projects/<image>"
~~~
   (Leave the `image:` line out if there's no image.)
4. Create `fa/data/projects.yml` with the same items and order, except:
   - `title`: use `title_fa` if it isn't empty. Otherwise translate `title_en` into Persian, but keep it in English if it's a product or brand name.
   - `description`: use `summary_fa` if it isn't empty. Otherwise translate `summary_en` faithfully (add no facts).
   - `categories`, `date`, `path`, `image`: identical to English.
5. `en/projects.qmd`, **exact content**:
~~~markdown
---
title: "Projects"
listing:
  contents: data/projects.yml
  type: grid
  sort: "date desc"
  categories: true
  grid-columns: 2
  fields: [image, title, description, categories]
page-layout: full
title-block-banner: false
toc: false
---

Selected projects. Each card links to the code or a demo.
~~~
6. `fa/projects.qmd`, **exact content**:
~~~markdown
---
title: "پروژه‌ها"
listing:
  contents: data/projects.yml
  type: grid
  sort: "date desc"
  categories: true
  grid-columns: 2
  fields: [image, title, description, categories]
page-layout: full
title-block-banner: false
toc: false
---

برخی از پروژه‌های من. هر کارت به کد یا نسخهٔ نمایشی پروژه پیوند دارد.
~~~

## Do NOT
- Don't add projects that aren't in the input. Don't invent descriptions.
- Don't change the navbar (that's T2.5.2).
