## Goal
Create the English ↔ Persian terminology file. It is the single source for (a) the public glossary page and (b) the translation prompt. Every entry starts as `status: draft`. The Owner reviews them in T5.1.2.

## Files you may create or change
- `shared/data/glossary.yml`

## Steps
1. Create `shared/data/glossary.yml`. Start with this comment block (**exact**):
~~~yaml
# English <-> Persian ML terminology.
# Used by scripts/build_glossary.py (public glossary page) and by prompts/translate_en_to_fa.md.
# Fields:
#   en:           English term (lowercase unless it is a proper noun)
#   fa:           preferred Persian term used on this site
#   fa_alt:       other Persian forms readers may know (list, may be empty)
#   farhangestan: official Academy of Persian Language equivalent ("" if unknown; owner fills)
#   note:         short usage note ("" if none)
#   status:       draft | reviewed   (only "reviewed" terms appear on the website)
~~~
2. Add **exactly these 60 terms**, in this order, one entry each:
   neural network, neuron, layer, activation function, weight, bias, loss function, gradient, gradient descent, backpropagation, learning rate, optimizer, epoch, batch, overfitting, underfitting, regularization, dropout, normalization, layer normalization, batch normalization, embedding, token, tokenizer, vocabulary, sequence, attention, self-attention, multi-head attention, query, key, value, transformer, encoder, decoder, positional encoding, feed-forward network, residual connection, softmax, logit, probability distribution, cross-entropy, inference, training, fine-tuning, pre-training, language model, large language model, convolution, convolutional neural network, pooling, feature map, recurrent neural network, hidden state, vanishing gradient, generalization, dataset, benchmark, hyperparameter, parameter
3. The shape of each entry (example):
~~~yaml
- en: "attention"
  fa: "توجه"
  fa_alt: ["اتنشن"]
  farhangestan: ""
  note: "On first use write «توجه (Attention)»."
  status: draft
~~~
   - `fa`: the term most commonly used in good Persian ML writing (university courses, well-known Persian books and blogs).
   - `fa_alt`: common alternatives, including the transliteration if people use it (e.g. «ترنسفورمر»). Use an empty list `[]` if there are none.
   - `farhangestan`: **always** `""`. Don't guess official terms.
   - `note`: `""`, or one short sentence when there's a real ambiguity (e.g. `bias` in neural networks vs statistics).
   - `status`: **always** `draft`.
4. Follow the Persian rules in AGENT_RULES §5.

## Verify
