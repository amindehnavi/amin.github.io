## Goal
A linter that catches the most common mechanical mistakes in Persian text, especially in machine-drafted translations: Arabic letters, missing نیم‌فاصله and English punctuation.

## Files you may create or change
- `scripts/lint_fa.py`
- `Makefile` (the `check` recipe only)

## Steps

### 1. `scripts/lint_fa.py`: spec
- Standard library only.
- Docstring: `"""Lint Persian text in fa/ for common mistakes. Run: .venv/bin/python scripts/lint_fa.py [--strict] [paths...]"""`
- **Files:** the paths given as arguments. If there are none, every `.qmd` under `fa/`, skipping paths containing `_site`, `_freeze`, `.quarto` or `assets`, and skipping `fa/glossary.qmd`.
- **What is checked:** prose lines only. Go line by line and:
  - skip lines inside fenced code blocks: a line starting with ```` ``` ```` or `~~~` opens or closes a fence (track which marker opened it)
  - skip lines inside display math: a line that is exactly `$$` (or starts with `$$`) opens or closes a math block; a single line `$$ … $$` is skipped
  - skip front-matter lines **except** lines starting with `title:` or `description:`
  - skip lines starting with `<!--`
  - on remaining lines, first remove inline code `` `...` ``, inline math `$...$`, URLs (`https?://\S+`), `{...}` attribute blocks and HTML tags `<...>`, then run the rules
- **Rules** (`P` = a Persian letter, regex class `[؀-ۿ]`):
  | code | level | regex (on the cleaned line) | message |
  |---|---|---|---|
  | E1 | error | `[يك]` | `Arabic ي or ك: use Persian ی or ک` |
  | W1 | warning | `(?<![؀-ۿ])(ن?می) (?=[؀-ۿ])` | `use ZWNJ after می/نمی (e.g. می‌شود)` |
  | W2 | warning | `[؀-ۿ] (ها|های|هایی|هایم|هایت|هایش)(?![؀-ۿ])` | `use ZWNJ before ها/های (e.g. داده‌ها)` |
  | W3 | warning | `[؀-ۿ]\s?[?,;]` | `use Persian punctuation ؟ ، ؛` |
  | W4 | warning | `[0-9]` **only on lines that contain a Persian letter**, after the cleaning above | `Latin digit in Persian prose: use ۰–۹` |
- **Output:** one line per finding: `<path>:<line>: <CODE> <message> | <the cleaned line, trimmed to 80 chars>`, then exactly `lint_fa: <files> files, <E> errors, <W> warnings`.
- **Exit:** 1 if E > 0. With `--strict`, 1 if E + W > 0. Otherwise 0.

### 2. `Makefile`
Change the `check` recipe to (TABs):
