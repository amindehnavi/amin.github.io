## Goal
A checker that makes sure every English page has a Persian twin (and vice versa), and that paired posts agree on their date, categories and series. It runs as `make check`.

## Files you may create or change
- `scripts/check_pairs.py`
- `Makefile`

## Steps

### 1. `scripts/check_pairs.py`: spec
- Uses `pyyaml` plus the standard library.
- Docstring: `"""Check that en/ and fa/ have matching pages and that paired posts agree. Run: make check"""`
- **Collect pages** in `en/` and in `fa/`: all files ending in `.qmd` or `.ipynb`, recursively, **skipping** any path that contains a folder named `_site`, `_freeze`, `.quarto`, `assets` or `.ipynb_checkpoints`, and skipping the generated `glossary.qmd`. Key each page by its path relative to the language folder **without the extension**, e.g. `posts/2026-10-hello-world/index`.
- **Exceptions:** `404` exists only in English. Ignore it.
- **Errors:**
  - an en key with no fa key → `ERROR missing in fa: <key>`
  - a fa key with no en key → `ERROR missing in en: <key>`
  - for paired keys that start with `posts/`, read both front matters and compare `date`, `categories`, `series`, `series-order` (a missing key counts as `None`). Any difference → `ERROR mismatch <key>: <field> en=<value> fa=<value>`
- **Warnings** (don't fail):
  - post where en is published (`draft` missing or false) but fa has `draft: true` → `WARN fa draft pending: <key>`
  - post where fa is published but en has `draft: true` → `WARN en draft pending: <key>`
- **Reading front matter:**
  - `.qmd`: the text between the first line `---` and the next line `---`, parsed with `yaml.safe_load`. If there is none, use `{}`.
  - `.ipynb`: load the JSON and take the first cell. If its joined `source` starts with `---`, parse the YAML between the `---` lines. Otherwise use `{}`.
- Output: the ERROR/WARN lines sorted, then exactly `check_pairs: <pages> paired pages, <E> errors, <W> warnings`.
- Exit **1** if E > 0, otherwise **0**.

### 2. `Makefile`
1. Add `check` to `.PHONY` (before `clean`).
2. In `help`, before `make clean`, add (TAB):
~~~make
	@echo "make check       run content checks (pairs, Persian lint, images)"
~~~
3. Before `clean:`, add:
~~~make
check: sync
	$(PY) scripts/check_pairs.py

~~~
