# T5.1.3 — Glossary page generator and navbar link

## Goal
Write `scripts/build_glossary.py`, which turns the **reviewed** terms of `shared/data/glossary.yml` into `en/glossary.qmd` and `fa/glossary.qmd` on every build. Then link the glossary in both navbars.

## Background (read only)
- The two generated `.qmd` files are build output: git-ignored and recreated by `make sync`, which runs before every render.

## Files you may create or change
- `scripts/build_glossary.py`
- `Makefile` (the `sync` recipe only)
- `.gitignore` (add 2 lines)
- `en/_quarto.yml`, `fa/_quarto.yml` (navbar only)

## Steps

### 1. `scripts/build_glossary.py`: spec
- Uses `pyyaml` plus the standard library.
- Docstring: `"""Generate en/glossary.qmd and fa/glossary.qmd from shared/data/glossary.yml (reviewed terms only)."""`
- Read `shared/data/glossary.yml` (UTF-8). Keep only entries with `status == "reviewed"`.
- Cell text: escape any `|` as `\|`. `fa_alt` is joined with `، ` (Persian comma + space). Empty values become an empty cell.
- **`en/glossary.qmd`**: sort the terms by `en.lower()`. Write exactly this, then one table row per term:
~~~markdown
---
title: "Glossary"
description: "English–Persian terms used on this site."
toc: false
---

The Persian terms this site uses for common machine-learning concepts. The Persian version of every post follows this list.

| English | Persian | Also seen as | Note |
|---|---|---|---|
~~~
  Row: `| <en> | <fa> | <fa_alt joined> | <note> |`
- **`fa/glossary.qmd`**: sort the terms by `fa`. Write exactly this, then one row per term:
~~~markdown
---
title: "واژه‌نامه"
description: "معادل‌های فارسی واژه‌های یادگیری ماشین در این سایت."
toc: false
---

معادل‌های فارسی که در نوشته‌های این سایت برای مفاهیم یادگیری ماشین به کار می‌روند.

| فارسی | English | معادل‌های دیگر | فرهنگستان | توضیح |
|---|---|---|---|---|
~~~
  Row: `| <fa> | [<en>]{.ltr} | <fa_alt joined> | <farhangestan> | <note> |`
- If there are **zero** reviewed terms, write the header part only, and instead of the table write the line `No terms yet.` (EN) or `هنوز واژه‌ای اضافه نشده است.` (FA).
- Print exactly: `glossary: <N> reviewed terms -> en/glossary.qmd, fa/glossary.qmd`
- Exit 0. If the YAML file is missing, print `error: shared/data/glossary.yml not found` to stderr and exit 1.

### 2. `Makefile`
Replace the `sync` recipe so it runs both scripts (TABs):
~~~make
sync:
	$(PY) scripts/sync_shared.py
	$(PY) scripts/build_glossary.py
~~~

### 3. `.gitignore`
Append:
~~~text

# Generated by scripts/build_glossary.py
/en/glossary.qmd
/fa/glossary.qmd
~~~

### 4. Navbar
- `en/_quarto.yml`: after the `CV` item, add:
~~~yaml
      - href: glossary.qmd
        text: "Glossary"
~~~
- `fa/_quarto.yml`: after the `رزومه` item, add:
~~~yaml
      - href: glossary.qmd
        text: "واژه‌نامه"
~~~

"
