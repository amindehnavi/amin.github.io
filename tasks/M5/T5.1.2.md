## Goal
Decide on the Persian term this site uses for each concept. Consistent terminology is one of the site's main values for readers.

## Steps
1. Open `shared/data/glossary.yml`. For each entry:
   - Fix `fa` if a better or more widely understood term exists.
   - Optionally look up the official equivalent in the Academy of Persian Language and Literature (فرهنگستان زبان و ادب فارسی) word database, and put it in `farhangestan`.
   - When you're happy with an entry, change `status: draft` to `status: reviewed`.
2. You don't have to finish all 60. Only `reviewed` terms are shown on the site, and you can review more over time.
3. Commit:
   ```bash
   git add shared/data/glossary.yml && git commit -m "T5.1.2: review glossary"
   ```
