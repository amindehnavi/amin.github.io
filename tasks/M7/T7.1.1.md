## Goal
Write the first real post, **Transformers from Scratch #1**, in English.

## Steps
1. **Scaffold** with an agent, running recurring task R1:
   ```text
   ... Then do ONLY the task in tasks/recurring/R1.md with SLUG=why-attention, TITLE_EN="Why Sequence Models Needed Attention", TITLE_FA="چرا مدل‌های دنباله‌ای به سازوکار توجه نیاز داشتند", SERIES=transformers-from-scratch, ORDER=1 ...
   ```
   The folder will be `en/posts/<YYYY-MM>-why-attention/`. Write down the full folder name; it's your **SLUG** from now on.
2. **Write** in `en/posts/<SLUG>/index.qmd`, following the template sections:
   - Run code in `{python}` cells. Heavy ML code is fine, because outputs are frozen. Make sure what it needs is installed in `.venv`, and list the extra packages in a `requirements.txt` in the post folder.
   - Use `make preview-en` while writing.
   - Replace **every** `TODO(owner)`. Delete sections you don't use.
   - Pick 1–3 categories (lowercase, dash-separated), e.g. `[transformers, nlp]`.
   - Optional: add `thumbnail.png` (1200×630, under 300 KB) and uncomment the `image:` line.
   - Fill in the "Terms in this post" table from `shared/data/glossary.yml`.
3. When finished, run `make render-en` once more, so the `en/_freeze/` outputs are up to date.
4. **Keep `draft: true`.** It's flipped at launch.
5. Commit:
   ```bash
   git add en/posts/<SLUG> en/_freeze && git commit -m "T7.1.1: post 1 English draft"
   ```

## Done when
- [ ] `grep -c "TODO(owner)" en/posts/<SLUG>/index.qmd` prints `0`
- [ ] `make render-en` succeeds
