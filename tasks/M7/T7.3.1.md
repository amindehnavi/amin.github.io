# T7.3.1 — Retire the test post and run the full QA

| | |
|---|---|
| Milestone › Checkpoint | M7 First post and launch › C7.3 Pre-launch QA |
| Who | 🤖 AGENT — level **basic** |
| Depends on | C7.2 approved |
| Time | ~15 min |

## Goal
Hide the hello-world test post, publish post #1 (draft → false), and run every automatic check on a clean build. The report becomes the launch checklist for the Reviewer.

## Inputs
- The Owner gives you `SLUG` (post #1's folder name) in the prompt.

## Files you may create or change
- `en/posts/2026-10-hello-world/index.qmd`, `fa/posts/2026-10-hello-world/index.qmd` (one line each)
- `en/posts/<SLUG>/index.qmd`, `fa/posts/<SLUG>/index.qmd` (one line each)

## Steps
1. In both hello-world posts, add the line `draft: true` to the front matter, directly after the `date:` line.
2. In both post #1 files, change `draft: true` to `draft: false`.
3. Run the QA commands below in order and put **all** output in the report.

## Verify
```bash
make clean && make build
```
```bash
make check; echo "exit=$?"
```
```bash
make check-links; echo "exit=$?"
```
```bash
make audit
```
```bash
grep -rn "TODO(owner)" en fa shared --include=*.qmd --include=*.yml --include=*.md | grep -v "^en/_site\|^fa/_site" ; echo "exit=$?"
```
```bash
grep -rn "{{[^<]" en fa shared --include=*.qmd --include=*.yml --include=*.html --include=*.scss --include=*.css | grep -v "_site/" ; echo "exit=$?"
```
```bash
grep -c "hello-world" public/blog.html public/fa/blog.html public/blog.xml public/fa/blog.xml public/sitemap.xml public/fa/sitemap.xml
```
```bash
grep -c "<SLUG>" public/blog.html public/fa/blog.html public/series.html public/fa/series.html
```
(Replace `<SLUG>` with the real value.)

## Done when
- [ ] `make build`, `make check` and `make check-links` all succeed (`exit=0`)
- [ ] There are no `TODO(owner)` and no `{{` placeholders outside build output (`exit=1` for both greps)
- [ ] `hello-world` appears **0** times in listings, feeds and sitemaps
- [ ] Post #1 appears in both blog listings and both series pages
- [ ] The `make audit` output is included for the Reviewer
