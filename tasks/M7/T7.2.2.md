# T7.2.2 — Edit the Persian post and publish-ready checks

| | |
|---|---|
| Milestone › Checkpoint | M7 First post and launch › C7.2 Post #1, Persian |
| Who | 👤 HUMAN (Owner) |
| Depends on | T7.2.1 |
| Time | ~1.5 h |

## Goal
Turn the machine draft into Persian you're proud of. (For later posts this step is R5, with the same checklist.)

## Steps
1. Run `make preview-fa` and open the post.
2. Read it fully and edit `fa/posts/<SLUG>/index.qmd` with this checklist:
   - [ ] It reads like it was written in Persian, not translated
   - [ ] Technical meaning is identical to the English (no added or dropped claims)
   - [ ] Glossary terms are used, with English in parentheses on **first** use only
   - [ ] نیم‌فاصله is correct («می‌شود»، «داده‌ها»)، with ی/ک, never ي/ك
   - [ ] Lines mixing English and Persian (`model.fit()`, `[GPT-2]{.ltr}`) display in the right order
   - [ ] Figure captions, alt text, callout titles, `title` and `description` are translated
   - [ ] Persian digits in prose
   - [ ] Any `TRANSLATOR NOTE` comments are resolved and deleted
   - [ ] The "New terms" from the agent's report have been added to `shared/data/glossary.yml` (as `reviewed` if you agree)
3. Run:
   ```bash
   make check
   ```
   It must end with `0 errors` for both check_pairs and lint_fa.
4. Commit:
   ```bash
   git add fa/posts/<SLUG> fa/_freeze shared/data/glossary.yml && git commit -m "T7.2.2: post 1 Persian edited"
   ```
5. Ask the Reviewer: **"Review checkpoint C7.2"**. The Reviewer compares the EN and FA versions section by section.

## Done when
- [ ] Every checklist item is ticked and `make check` passes
