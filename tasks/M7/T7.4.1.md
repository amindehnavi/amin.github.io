# T7.4.1 — Launch and announce 🚀

| | |
|---|---|
| Milestone › Checkpoint | M7 First post and launch › C7.4 Launch |
| Who | 👤 HUMAN (Owner) |
| Depends on | Reviewer PASS on C7.3 ("launch gate") |
| Time | ~1 h |

## Steps
1. Push:
   ```bash
   git tag approved/C7.3 && git push && git push --tags
   ```
   Wait for the green **Publish site** run.
2. **Smoke test** on your phone and laptop: home (EN/FA), post #1 (EN/FA), the language switch on the post, comments box, dark mode, search.
3. **Telegram:** Actions → *Announce post on Telegram* → Run workflow → slug = `<SLUG>`, **dry_run ✓**. Read the message in the log. If it's fine, run it again with **dry_run unticked**. Check the channel.
4. **Spread it:**
   - **Virgool (ویرگول):** publish the Persian post, or a summary of it, with a clear link to the original at the top.
   - **LinkedIn:** a short English post with the English link (the social card appears automatically).
   - Share the channel in 2–3 relevant Persian ML Telegram groups or communities, following each group's rules.
5. Tag the launch:
   ```bash
   git tag launch && git push --tags
   ```
6. Tell the Reviewer: **"Launched — switch to operating mode"**. The Reviewer then refreshes the plan for the next posts (M8).

## Done when
- [ ] The site is live, post #1 is announced, and the `launch` tag is pushed 🎉
